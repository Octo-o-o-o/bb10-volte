# 在手机应用中连接电脑

本地候选桌面 r32／手机版 0.1.0.33 提供可选的电脑授权入口。只在手机上使用 VoLTE 无需配对；首次使用桌面版、换电脑或原有授权丢失时才需要。手机必须已有可用的 Root，应用不会替原厂系统取得 Root。安装和实机验收状态见 [SQW100-4 本次复测](SQW100-4-RETEST-2026-11-07.md)。

1. 在桌面版的连接恢复页生成配对材料，导出 `bb10-pair-…-request.json`，复制到手机内部存储 Downloads。私钥留在电脑。
2. 打开手机 **BB10 VoLTE → 管理与恢复 → 连接电脑**，点击 **读取 Downloads 请求**；有多份请求时，用选择按钮选中本次文件。核对页面上的电脑指纹与桌面版一致，再点击 **授权这台电脑**。
3. 将手机提示的 `bb10-pair-…-result.json` 复制回电脑，在桌面版导入。桌面核对请求、电脑公钥和手机主机公钥，再验证 SSH 与 Root；通过后继续原任务。

请求文件只包含公钥和请求编号，不含密码或私钥。手机使用应用内置的固定程序处理请求，保留原有授权并备份。未运行 SSH 时，只在现有配置允许的情况下临时启动 USB 服务；不会修改开机开关。若页面提示授权已保存但服务未启动，使用现有 Root 工具开启 USB SSH，再由桌面验证。

只有安装主应用后才能使用这个入口。尚未安装主应用时，可使用现有本机 BAR 安装器，或桌面版保留的终端备用步骤。旧版独立“电脑配对”应用是个案辅助工具，不是所有用户的必装依赖。不要导入来源不明的电脑请求。
