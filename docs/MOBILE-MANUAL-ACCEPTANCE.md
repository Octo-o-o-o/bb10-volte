# 手机 0.1.0.18 / 桌面 r19：一次集中人工验收

本轮候选是 v18 原生应用与 r19 桌面，后台服务保留逐字一致的 r18。新增验收重点是桌面点击首装、手机操作等待、上次状态缓存与手动检查、通话验收保存反馈，以及 Q10 和换卡组合。v12/r18 已在 Passport／移动和 Q20／联通完成恢复、卸载、全新安装、三次较长通话、双向长短及相同内容短信和验收记录保留；准确范围见[验收记录](MOBILE-VALIDATION.md)。这些结果不能直接填写为 v18 界面通过。

当前候选**尚未公开发布**。使用本次最终 BAR、桌面和服务哈希记录各项结果；不能由构建或 IMS 注册替代实机验收。机主已接受 Passport 此前孤立的唤醒重启，保留历史事实而不声称根因已修复。Q20 的 Android APK 引导内核重启是另一事件，该引导路线已退役，不再复测。

Root 成功前系统可能拒绝启动应用；不要反复点图标制造失败。仅在应用已能启动后验证 helper 延迟时的等待提示。手机系统权限和正常菜单重启仍由机主操作。

本清单不用重跑坏签名、ZIP 上限、QNX 锁释放等自动探针。重点是实际安装版本、系统权限、现有任务续接和用户能看到的完整操作。各项写“通过 / 未通过 / 未测”，不要用旧版本记录填新版本结果。

第一、二轮针对三个基线机型的**自动协议 2**流程。旧实验路线的 23 选项与恢复范围见下方独立段落，不把自动原件导出回执或完整卸载承诺套到 trial。

## 先确认本轮起点

- 目标包：手机 **0.1.0.18**、桌面 **0.5.0-r19**、后台服务 **r18**，管理协议 **2**；核对同一次候选交付的 SHA256SUMS 与产物回读报告。
- 逐台填写准确型号、OS、Root、SIM 运营商、已有服务版本和起始状态；不把一台的结果复制给另一台。原件备份保留且不公开。
- 已有任务先检查原记录，只有界面允许且安全时才继续；没有任务则从实际状态开始，不重发历史操作。v12 修复的运行目录权限已在两台全新安装验证，新机仍须核对。
- 历史掉话与启动超时保留在验收记录，新的通过只覆盖本轮设备、SIM 和操作窗口，不等于所有历史根因已解决。
- 先正常解锁，按原 Root 方案等待本机入口恢复。若还不能检查原状态，停在此步排查；不要反复重启、重新 Root 或刷机。SSH 未返回不能单独证明本机 Root 失效。

## 另行验收：受控实验路线

实验页应有旧 4 配置与 19 个精确后缀配置，共 23 项；其中 13 组可进入受控手动试测，6 组 Passport 只读。逐项核对名称与准确硬件，不用通用配置替代其他后缀。没有对应实机时只能记为选项/准入检查，不能填写通话通过。

- [ ] 切换 profile 清除旧准入，每次开始都重新检查已装 profile 与当前兼容条件；只读项不出现写操作。
- [ ] 普通 13 试测的说明明确：无电信附着修改，恢复以启动时 PPS journal 为准，不宣称自动协议 2 原件导出回执。
- [ ] 停止实验适配会关闭旧自启动并等待恢复。更新前必须先停用恢复且无悬挂 install-transaction；中断记录保留，拒绝盲重试。
- [ ] “卸载实验启动项”保留私有载荷与备份，不能显示为自动协议 2 的完整移除；没有新增 legacy rollback。
- [ ] 导出的试测记录带 last_checked_not_live，用户可分辨上次检查与实时状态。语音/SMS仍须在每个真实组合上独立验收。

## 记录与发布判断

每组结果只公开日期、候选版本、准确型号/OS/Root 方案、运营商名称、操作阶段、通过/未通过/未测和必要的脱敏错误码。不要附个人操作 ID、私有路径、密钥、SIM 身份、电话号码、原始回执或通信日志。

未测项目保留“未测”，不能写“手机版全部通过”。最终 v18 / r19 全量检查、包回读以及上面准备发布范围内的实机项目完成后，才发布同一组字节。后续人工结果可作为绑定同一哈希的独立验收附件，避免为补录结果改变已验证字节；源码内的已知结果见[MOBILE-VALIDATION](MOBILE-VALIDATION.md)及[公开设备证据](../materials/mobile-device-validation-2026-11-02.json)。

原厂未 Root 手机仍走电脑首次 Root；本清单不提供纯手机从零 Root，也不要求修改安全设置、代替用户接受系统权限或绕过锁屏。

启动前边界：Root 生效前反复点图标已在本机触发 Launcher 权限拒绝与 Navigator 循环等待，随后黑屏；不要用这种方式测试应用内 Root 等待。仅在系统已允许应用进程启动后验证 helper 延迟，不得改系统门禁或强行制造 Root 失败。
