# Windows r60 and mobile 0.2.5.0

- **Desktop & mobile overseas editor UI and reliability fixes**:
  - Desktop `OverseasCarrierDialog` (880×680, scrollable tabs, bottom button bar always visible) and `AutoCarrierWindow` (780×700, scrollable details pane) now pass live bilingual geometry checks in both Chinese and English; displays upfront service-running warnings, preserves non-overlapping carriers in multi-carrier configs, injects `observed_data_apn` only when the preset PLMN matches the inserted SIM, accepts fullwidth `，` separators, and localizes validation/connection errors.
  - Native mobile `OverseasCarrier.qml` fixes the `loadingForm` initialization deadlock, wires `overseasActionFinished` with an `ActivityIndicator`, disables auto-capitalization/autocorrect on technical fields, isolates overseas errors from the Home screen error banner, and aligns `entry.py` Base64 decoding limits with the full 16 KiB raw JSON ceiling.
- **Device engine hardening, ISIM credential preservation & PPS deduplication**:
  - Writes `IR.92` `UsePreconditions` as native PPS booleans (`b:false`/`b:true`, while still accepting legacy `0`/`1` inputs); validates `SIP_Timer_CSFB` in seconds (`0..120`) and adds allowlisted `IPsec`, `SIP_transport`, and `RegExpiration` IMS PPS keys; preserves native ISIM `EF_IMPU`/`EF_IMPI` by skipping synthetic `imsconfig_user.xml` when `allow_isim=True` on USIM+ISIM cards; adds bounded profile-load wait for `AlwaysOn=false`; preserves explicit APN priority order for `experimental` profiles and keeps `460-15` blocked from overseas overrides.
  - Fixes `lte_bands_disabled` to fire only when LTE band capability is `0` with radio on and LTE absent (eliminating false positives on 3G/2G/searching); hardens P-CSCF host route sync with a bounded retry queue, exit cleanup when `ims_rrm` terminates, and running-phase incremental sync; unifies `redact_ipv6_addresses` across device and desktop feedback while adding `key::ipv6`, 8-group `:port`, and overseas E.164 / contextual dial-number redaction.
  - Deduplicates `unified_dca` PPS RPC helpers and radio-override rollback paths, defers stock template binding for `0.xml` + `data_apns: ["auto"]`, enables safe same-boot retry after saving an overseas profile on an unsupported SIM, and registers `r59` in `PREVIOUS_PAYLOADS` for safe in-place upgrades.
- **Schema 2 overseas catalog (297 clean entries) & 214 KB mobile bundle slimming**:
  - Upgrades `materials/overseas-carriers.json` to Schema 2 (297 entries, 61.5 KB, -33% size) by hoisting `mcc_regions` and `default_bb10_status: "untested"`, fixing Tier-1 MNO ranking (e.g., `311-480` Verizon Wireless, `440-10` NTT DOCOMO), excluding lab/reserved/junk rows, and preferring dedicated `type="ims"` entries while keeping full Apache-2.0 attribution. Drops 4 unread historical intake JSONs from mobile BAR and OTA ZIP packages (-214 KB).
  - Mainland China (`460-*`) SIMs keep zero regressions, byte-identical XML/PPS, and the clean 1-click UI. Adds `overseas` subcommand to `tools/ai_skill.py`, slims `tools/kt_isim_trial.py` to a thin compatibility wrapper, and adds live catalog + dialog geometry checks to the frozen Windows EXE `--self-test`.

This is an experimental release; overseas reference presets and new runtime paths have not completed physical hardware acceptance. The macOS download remains frozen at r43.
