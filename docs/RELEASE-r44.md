# 桌面 r44 / 手机版 0.1.0.44：已开放型号的鲜机检查

2026-11-10。macOS 仍停在 **v0.5.0-r43**，本次没有新的 Mac 安装包。

- 已经开放、但没有专用旧服务迁移路径的型号，只有在全部已知旧服务目录都不存在时，才按新机检查和安装。未知型号，以及任何已知旧服务残留，仍然拦截。不会借用另一型号的恢复目录。
- 已发布的 r42／r43 后台仍按原校验进入升级，原备份和恢复机制保留。
- 手机版同步为 **0.1.0.44**。SQC100-5 上，签名运行时检查曾返回“准备开启 VoLTE”，机主确认了该界面。这只说明检查页面，不是通话、声音、短信或数据验收。
- Windows 安装包继续包含 r43 的界面绘制修复和准备缓存复用。已经能用的手机不需要为这次更新重新刷机或重做 Root。遇到鲜机检查报错时，再安装 0.1.0.44。

历史实测、未测和已知问题仍按原版本、原样机保留。离线构建和下载校验不作为新的实机功能验收。Windows EXE 仍没有 Authenticode 发布者签名。
