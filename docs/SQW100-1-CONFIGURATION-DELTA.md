# SQW100-1 本次适配的实际改动

对象：SQW100-1／WINDERMEREEMEA／10.3.3.3216。最终候选为 Windows r29、手机版 0.1.0.30。移动 460-00 的最终验收已完成；移动 460-07、联通 460-01 保留各自已验收版本；电信 460-11 语音和数据已适配，短信发送状态与重复收信问题继续单列。

当前移动 460-00 的恢复日志列出 **3 个 PPS 对象、7 个字段**。具体逐字段前后值见 [机器可读对照](../materials/sqw100-1-configuration-delta-2026-11-07.json)。另外有四份 DCA 文件、私有 IMS 身份配置及临时运行文件；因此“7 个字段”不是整个安装的全部改动数。SIM 身份内容只保存在本机私有证据中。

电信额外复用了已存在的 446.xml 代理修复：在路径、归属网络和原文件哈希全部吻合时，只从生成副本的 `ctnet` 上网条目移除 `10.0.0.200:80`，保留原厂和 MMS 配置。本机 174—179 的证据读回确认生成配置及三个系统对象中的旧代理已移除。这项改动不应用于移动、联通或任意未知运营商模板。

没有重刷系统、替换 radio 固件，也没有把外部反馈的 PS_ONLY 或关闭 IR92 预条件作为全机型统一设置。当前移动专用临时副本确实包含 EarlySdp 调整；这与修改 `UsePreconditions` 是不同的操作。

从已通过移动 460-00 功能测试的私有候选到最终 0.1.0.30，18 个后台文件中只有 5 个变化：`carrier_policy.py`、`compatibility.py`、`profiles.py`、`unified_install.py`、`unified_migrate.py`。这些用于准入、兼容与升级，并保留另一台 SQC100-4 的限制；没有再次修改该候选的语音或短信引擎。移动 00 的新增需求主要是精确登记和产品集成，不能据此假定所有新后缀只需加入名单。

主要证据：044／164／308 的模板；410 的原始策略和六个原生文件；453／458 的恢复及模块释放；461 的升级备份和五文件差异；466／467 的当前启动；472 的 57 个签名运行文件与 18 个后台文件；475 的最终验收；476 的配置差异。长短信、相同内容短信和 HTTP/HTTPS 依据436的私有候选实测，最终版另做了通话、数据、短短信和页面复核。
