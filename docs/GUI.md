# bb10-volte 使用指南

[English](GUI.en.md)

这是面向 BlackBerry 10 设备的桌面界面，与命令行共用固定流程。Windows 可使用独立 [EXE](WINDOWS-EXE.md)，macOS 可按 [DMG 指南](MACOS.md) 使用 `.app`；用户无需单独安装 Python。源码方式需要 Python 3.14（含 Tk）和 OpenSSH。两种方式都需要已准备好的个人 Root SSH 配置及可用网络连接，不需要 Codex、其他 AI 工具或云端账号。Mac 直连手机的 USB 网络需要单独验证。

使用源码时，从完整解压后的发布目录双击 `Start-GUI.cmd`，或运行 `python tools/gui.py`。请保留整个目录；不能只复制界面脚本。安装包校验不符时应换回完整发布包，客户不能通过重新生成清单跳过检查。

## 1. 连接与预检

选择这台手机的个人 `ssh_config`，默认别名为 `bb10-root`。已有旧配置若只定义 `q10-root`，请在别名栏填入 `q10-root`。也可以留空配置路径，使用本机已配置的 OpenSSH 别名。工具强制校验已知主机密钥，不会接受未知主机、替换密钥或修改网卡设置。

选择运营商配置或点击“编辑 / 导入配置”，可编辑 MCC/MNC、数据及 IMS APN、IP 类型、域名、等待时长和自动启动，支持 JSON 导入导出。Q20 / Q30 或未实测运营商需勾选实验试用；配置变化使旧预检失效。详见 [配置指南](PROFILES.md)。

点击“运行预检”，自动识别 Q10 / Classic（Q20）/ Passport（Q30），检查 OS、Root、4 个原生文件哈希、SIM/MCC/MNC、LTE、所选 APN、原厂配置、现有服务与安装前状态。

预检将四个检查模块和配置请求上传到随机临时目录，仅授权需要执行的脚本，完成后清理这些文件；不安装服务或改写调制解调器、PPS、APN、VPN。断线可能留下临时目录。完整预检需要已 Root 的手机。

结果解释：

- 符合当前适配条件：只说明技术条件匹配，仍需运营商开通及通话验收。
- 有条件尚未就绪：SIM、Root、LTE 或数据网络未就绪，处理后重试。
- 未实测适配 · 可实验试用：试用已开启且技术条件通过；仍须逐台通话验收。
- 需要适配：SIM 与配置不符、ISIM、原厂配置不符或未知身份格式，禁止安装。
- 关键技术条件未通过：身份冲突、版本或原生哈希不符，禁止安装。试用开关不能绕过。

旧服务正在运行时，兼容性可以通过，但安装前状态不会通过。更新前先挂断电话，执行“停用并恢复”，再重新预检。

## 2. 固定安装流程

确认已备份、此卡已经开通 VoLTE、当前没有通话。检查通过后，点击“安装并验证”；已有完整且停止的服务显示“更新并验证”。

流程为：校验固定清单 → 连接与上传 → 最新预检 → 手机上再次预检 → 写入固定版本 → 回读全部文件 → 启动 → 按配置等待注册（默认 180 秒）。整个过程使用同一套代码和规则，界面不会生成临时修补命令。

安装按所选配置设置自动启动；关闭后仍能手动启动。注册观察默认 180 秒，可在编辑器修改。首次启动可能短暂重载无线网络。保持连接，不要换卡、拨号或同时运行另一安装工具；操作期间锁定连接、配置和按钮。

“IMS 注册通过”还不是通话验收完成。必须用系统拨号器验证呼入、呼出、双向声音、全程 4G、脱离电脑及正常重启后的复测。工具不自动拨号。观察超时仅标记“注册待确认”，不重复安装或自动判为成功。

**安装完成后的重启等待说明：** 2026-10-28 的 v0.3.2 Q10 正常重启实测，从系统启动到 IMS 注册共约 **3 分 48 秒**；其中 BB10 和 Root 启动约 **3 分钟**，Root 就绪后到 IMS 注册约 **45 秒**（实测 44.7 秒）。**45 秒不是整机开机时长。** 这是北京联通单机记录，实际耗时以本机和网络状态为准。看到桌面、4G 或 Root 成功提示时，请继续等 IMS 注册通过再测试通话。请优先从手机电源菜单正常重启；此前电脑命令触发的一次黑屏原因未确定。程序在“IMS 注册通过，待通话验收”处也会显示这段计时说明。

## 3. 恢复与中断

“停用并恢复”关闭自动启动，停止本项目服务，并回读原策略和清理状态。只恢复本项目拥有的配置；外部修改或所有权冲突会阻止继续处理。

断线后先重新预检、查看状态。安装中断会保留 `install-transaction.json` 或表现为不完整目录；禁止盲目覆盖、删除恢复记录或重新刷机。当前版本会识别并阻止重复写入，但尚未提供任意中断点的自动修复。需要维护者根据私有安装记录人工处理。

本界面负责已 Root 手机的 VoLTE 服务。初次 Root 的镜像准备和会清空用户数据的刷写仍按 [完整安装文档](INSTALL.md) 执行，界面不发起刷机。

## 4. 报告和兼容性范围

“导出脱敏报告”只保存允许的检查项、结果和机型/系统/MCC/MNC，不包括完整 IMSI、IMEI、ICCID、PIN、手机号、SSH 密钥、主机地址或原始 SIP 日志。工具不自动上传报告。

Q20 / Q30 显示“未实测适配 · 可实验试用”；技术条件不符时仍禁止安装。报告还包含所选配置和文件指纹，便于反馈；不要在自定义名称填写个人信息。实际通话证据仍只有北京联通的一台 Q10，不是全国通用承诺。见 [兼容性矩阵](COMPATIBILITY.md)。Q20 / Q30 不得刷写本仓库的 Q10 Root 镜像。
