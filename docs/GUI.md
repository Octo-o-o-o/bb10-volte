# bb10-volte 使用指南

[English](GUI.en.md)

0.3.3 新增“更多 → 社区研究与适配进展”。预检与导出报告包含精确匹配的社区证据和只读来电配置快照，不能替代通话验收。Passport 自动安装、启动及恢复暂缓，详见[社区研究](COMMUNITY-RESEARCH.md)。

当前开发源码使用“连接手机 / 连接帮助”新流程；已发布 r6 及更早应用的入口名称可能仍为“检查设备 / 首次使用”。本次源码改动尚未作为新 EXE/DMG 发布。

这是面向 BlackBerry 10 设备的桌面界面，与命令行共用固定流程。Windows 可使用独立 [EXE](WINDOWS-EXE.md)，macOS 可按 [DMG 指南](MACOS.md) 使用 `.app`；用户无需单独安装 Python。源码方式需要 Python 3.14（含 Tk）和 OpenSSH。首次准备可从“首次使用”进入；Windows Q10 支持材料、个人镜像与明确确认后的刷写，本分支另有 macOS 14+ 原生首次准备与分阶段执行的实验入口（未实机首刷，旧 r5 DMG 不含），见[Mac 指南](MACOS.md#mac-能否首次-root)。连接需要对应设备的个人配置及可用网络，不需要 Codex、其他 AI 工具或云端账号。当前 Q10 已完成 Mac USB 网络、日常检查和通话实测，范围见[Mac 连接指南](MACOS.md)。

使用源码时，从完整解压后的发布目录双击 `Start-GUI.cmd`，或运行 `python tools/gui.py`。请保留整个目录；不能只复制界面脚本。安装包校验不符时应换回完整发布包，客户不能通过重新生成清单跳过检查。

## Mac 连接提示

Mac 主界面的连接卡提供接线、解锁、个人配置/恢复的简短步骤及“Mac 连接说明”入口；指南随应用提供，无需联网。未 Root、有 Root 但无文件、有 Root 且有个人材料三种情况的具体操作见[Mac 指南](MACOS.md)。没有旧 Windows 文件时可在已有有效 Root 终端为 Mac 独立授权，`PAIR` 会持久追加手机公钥；没有材料也没有有效 Root 终端则不能直接连接。应用不自动改 IP、装旧 Link 或降低主机校验。

这些界面提示与首次向导修复属于当前仓库源码；已发布 `0.3.2-r5` DMG 尚不包含这些改动。r5 主界面已实测可用，但首次向导的 Python `-c` Root 检测会被部分手机策略拒绝并误报连接问题，USB 事实也可能未显示。不要把源码测试等同于新 DMG 验收。

## 1. 连接与预检

主界面显示最近连接状态、运营商和检查结论；只有待处理项会出现在检查列表。点击“检查详情”查看全部检查。“更多”中保留服务状态、停用恢复、报告导出、高级连接设置与指南。

主界面与向导共用轻量圆角组件：按钮、下拉框、输入框、页签和进度条保持一致的视觉层级，并保留标准键盘操作与焦点提示。滚动条仅在内容超出可见范围时显示，窗口缩放或说明内容变化时自动更新。主题离线内置，无额外运行依赖。

首页点击“连接手机”，程序查找已有连接并检查实际状态；需要处理时打开“连接帮助”。无需先找到 SSH 配置文件。旧 `q10-root` 别名仍会匹配；高级手动配置与别名位于“更多 → 高级连接设置”。曾成功连接的电脑重新打开应用时，会复查一次当前手机，不会自动安装或刷写。

“连接帮助”可直接选择以前刷机的整个文件夹，识别唯一一组登录材料并在确认来源后建立本机配置；也可通过手机已有有效 Root 终端重新授权。手机授权的编号、密钥和步骤在关闭后保留。确认手机尚未 Root 时，再进入独立的首次准备；连接失败不代表未 Root。完整场景见[连接流程](CONNECTION-FLOW.md)，权限前提见[恢复连接](RECOVER-CONNECTION.md)。

选择运营商配置或点击“自定义”，可编辑 MCC/MNC、数据及 IMS APN、IP 类型、域名、等待时长和自动启动，支持 JSON 导入导出。档案 ID 和原厂配置指纹放在“高级”页。识别到 Q20 / Q30 或选择未实测配置后显示实验试用选项；配置变化使旧预检失效。详见 [配置指南](PROFILES.md)。

连接验证后继续检查，自动识别 Q10 / Classic（Q20）/ Passport（Q30），检查 OS、Root、4 个原生文件哈希、SIM/MCC/MNC、LTE、所选 APN、原厂配置、现有服务与安装前状态。收起已通过的明细不会减少检查项目或放宽条件。

预检将四个检查模块和配置请求上传到随机临时目录，仅授权需要执行的脚本，完成后清理这些文件；不安装服务或改写调制解调器、PPS、APN、VPN。断线可能留下临时目录。完整预检需要已 Root 的手机。

结果解释：

- 符合当前适配条件：只说明技术条件匹配，仍需运营商开通及通话验收。
- 有条件尚未就绪：SIM、Root、LTE 或数据网络未就绪，处理后重试。
- 未实测适配 · 可实验试用：试用已开启且技术条件通过；仍须逐台通话验收。
- 需要适配：SIM 与配置不符、ISIM、原厂配置不符或未知身份格式，禁止安装。
- 关键技术条件未通过：身份冲突、版本或原生哈希不符，禁止安装。试用开关不能绕过。

旧服务正在运行时，兼容性可以通过，但安装前状态不会通过。更新前先挂断电话，执行“停用并恢复”，再重新预检。

## 2. 固定安装流程

检查通过后会显示确认框与适合当前状态的操作。确认已备份、此卡已经开通 VoLTE、当前没有通话，再点击“安装并验证”。已有可启动服务显示“启动并验证”；需要更新时使用“更多 → 安装 / 更新并验证”。

流程为：校验固定清单 → 连接与上传 → 最新预检 → 手机上再次预检 → 写入固定版本 → 回读全部文件 → 启动 → 按配置等待注册（默认 180 秒）。整个过程使用同一套代码和规则，界面不会生成临时修补命令。

安装按所选配置设置自动启动；关闭后仍能手动启动。注册观察默认 180 秒，可在编辑器修改。首次启动可能短暂重载无线网络。保持连接，不要换卡、拨号或同时运行另一安装工具；操作期间锁定连接、配置和按钮。

“IMS 注册通过”还不是通话验收完成。必须用系统拨号器验证呼入、呼出、双向声音、全程 4G、脱离电脑及正常重启后的复测。工具不自动拨号。观察超时仅标记“注册待确认”，不重复安装或自动判为成功。

**安装完成后的重启等待说明：** 2026-10-28 的 v0.3.2 Q10 正常重启实测，从系统启动到 IMS 注册共约 **3 分 48 秒**；其中 BB10 和 Root 启动约 **3 分钟**，Root 就绪后到 IMS 注册约 **45 秒**（实测 44.7 秒）。**45 秒不是整机开机时长。** 这是北京联通单机记录，实际耗时以本机和网络状态为准。看到桌面、4G 或 Root 成功提示时，请继续等 IMS 注册通过再测试通话。请优先从手机电源菜单正常重启；此前电脑命令触发的一次黑屏原因未确定。主界面只显示简短的通话验收提示，详细计时保留在本指南中。

## 3. 恢复与中断

“更多 → 停用并恢复”关闭自动启动，停止本项目服务，并回读原策略和清理状态。只恢复本项目拥有的配置；外部修改或所有权冲突会阻止继续处理。

断线后先重新预检、查看状态。安装中断会保留 `install-transaction.json` 或表现为不完整目录；禁止盲目覆盖、删除恢复记录或重新刷机。当前版本会识别并阻止重复写入，但尚未提供任意中断点的自动修复。需要维护者根据私有安装记录人工处理。

通过“连接帮助 → 手机尚未 Root，或不确定”可在明确确认状态后打开首次 Root 准备。首次准备集成 Windows Q10 Root 准备与确认后刷写，以及 macOS 14+ 实验原生准备与分阶段执行（未实机首刷）；刷写会清空手机数据，不能用它修复已有 Root 的密钥问题。其他机型和 Mac 首次刷写的实际边界见[首次使用](FIRST-RUN.md)。

## 4. 报告和兼容性范围

“更多 → 导出检查报告”只保存允许的检查项、结果和机型/系统/MCC/MNC，不包括完整 IMSI、IMEI、ICCID、PIN、手机号、SSH 密钥、主机地址或原始 SIP 日志。工具不自动上传报告。内部错误代码保留在报告中，主界面显示处理建议。

Q20 显示“未实测适配 · 可实验试用”；Passport 显示“恢复策略待验证”，暂缓自动操作。技术条件不符时仍禁止安装。报告还包含所选配置和文件指纹，便于反馈；不要在自定义名称填写个人信息。实际通话证据仍只有北京联通的一台 Q10，不是全国通用承诺。见 [兼容性矩阵](COMPATIBILITY.md)。Q20 / Q30 不得刷写本仓库的 Q10 Root 镜像。

社区作者补充了自启动卡开机动画的反馈：未验收机型／运营商组合须在“自定义 → 运行选项”关闭自动启动后重新检查。桌面、CLI 和手机端均限制为手动启动；已验收 Q10 基线保留原行为。
