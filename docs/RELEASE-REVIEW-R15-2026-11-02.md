## 审查结果与修复

1. Root 页支持重新检测。缺失、断连或多设备元数据不再直接丢弃已经准备的镜像；确认是另一型号时仍作废旧准备。实际唯一型号、系统与清空确认仍是刷写条件。
2. 下载、导入、Root、升级和自动安装均按完整型号说明支持边界。图 3 的 SQC100-3、图 4 的其他 Passport 后缀不能仅凭同系列固件绕过。独立系统恢复／Root 目的必须显式选择，不等于新增 VoLTE 支持。
3. 手动候选配置绑定准确后缀与运营商，设备端再次检查六个原生文件、OS、Root、SIM、LTE 和干净可恢复状态。安装后不自动启动，自启动固定关闭；SQW100-1/-3 仍被原生停止／恢复限制阻断。
4. 自动适配只保留 SQN100-3、SQC100-2、SQW100-4，原生二进制和语音／短信补丁不变。r14 精确载荷指纹和固定更新文件集合保留，未知载荷不接受覆盖升级。
5. 整合发现反馈投影遗漏 `variant_trial`，会丢失测试目标与六文件摘要；已增加固定字段、路径和 SHA-256 格式校验，仍拒绝任意路径和原始资料。反馈回读再次投影，二次导出不丢失这些字段。
6. 整合发现 `block`、`adapt`、不支持型号和不支持 SIM 可能记为普通完成；已统一记为需处理，并覆盖回归。真实未知异常只保存类型与代码位置，反馈失败不阻断设备事件。
7. 教程与 README 原本写“反馈尚待发布”“仅 preview”，已改为 r15 实际入口。教程录制基线如实保留为 r14 加反馈，提示 r15 新增型号检查。中英文官网均提供候选范围与只读限制。
8. 实际窄屏／桌面截图发现指南正文继承首页章节标签的 10 px 等宽字体；已为指南正文恢复 16 px 正文字体及正常字距，并在浏览器测试中核验，避免用户难以阅读步骤和限制。

图 1 只有“卡联机”，无法确定根因；图 2 的旧 `/var/addons/volte` 安装器不是本项目 `/var/addons/bb10-unified-volte`，不能将本轮修复当成该安装器已解决。四张图的分别追问见[完整方案](ALL-VARIANTS-COVERAGE-PLAN.md)。

## 验证与发布边界

回归覆盖型号／运营商分类、未知或错误原生文件、候选同意与安装／启动分离、Root 重连与错误型号、r14 迁移和备份保护、反馈重试／跨会话／脱敏、GUI、载荷及公开材料清单。发布验证另核对源码 ZIP、Windows 冻结模块、Mac 签名公证与挂载包自检、中英文窄屏页面、视频播放／跳转，以及 GitHub 与 R2 的完整下载字节。

最终测试数量、制品 SHA-256、冻结源码提交、签名／公证和下载回执以 Release 附件 `bb10-volte-0.5.0-r15-release-validation.json` 及 `SHA256SUMS.txt` 为准。发布网站前需两处附件验证完成；官网、README、应用版本及源包保持 r15 一致。

本轮为实施会话复审，不宣称独立第三方验收。本轮不连接或修改手机；新增型号、Intel 实机运行／USB 刷写、最低桌面 OS 版本和长期稳定性仍未验收。既有九组合历史语音记录与 r14 两组合短信记录保留原日期和范围。
