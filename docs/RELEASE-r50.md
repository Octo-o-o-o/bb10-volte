# r50 / 手机版 0.1.0.50

- 开机交接遇到暂时的原生探测超时会重新取证。后台本次开机未启动时，通过检查后可重试连接。
- 手机上的安装任务中断后可检查回执并继续。新版可归档已核验且未改系统配置的旧准备事务；已开始写入的事务继续核对原载荷和原始备份。
- 在 DCA 运营商配置写入前保存逐文件事务记录。可恢复有记录的部分写入，并保留无法确认归属的冲突现场。

## 升级和验证

Windows 和手机版更新。macOS 封板于 v0.5.0-r43。已有后台按两端检查结果停用和更新，保留原始备份。正常重启仍用于释放本次开机已加载的原生资源，并用于 Passport 的指定入网策略切换。

如果旧手机版卡在「上次操作结果未知」而打不开应用内更新，可用 Windows r50 安装器先更新手机版 BAR，再打开原任务并选择「检查并继续」。

旧版部分写入可能没有足够的逐文件记录。遇到配置冲突时保留原件和报告。离线故障注入覆盖开机探测、部分写入及安装事务，用户设备上的具体原因和新版本真机结果待验证。
