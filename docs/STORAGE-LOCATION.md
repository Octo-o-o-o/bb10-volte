# 桌面大文件目录与可选清理

未配置时，下载和准备仍使用原来的个人目录。用户从「更多」、首次使用或系统升级打开「存储位置与磁盘清理」后，可以另选一个已有文件夹。之后开始的自动下载写入该文件夹的 `downloads`，新的 Root 和原版升级准备写入该文件夹的 `root-kit-<编号>`。

选择本身不抢占主窗口，不移动已有文件，也不改道已经开始的下载、准备或刷写。一次准备在进入时记下本次目录，之后再改存储位置只影响下一次。所选位置缺失、是符号链接/联接、位于程序自身目录（含打包后的程序所在文件夹）或个人材料目录内部、或者当时及之后不能写入时，新的下载和准备继续使用原来的位置。所选文件夹里的 `downloads` 如果是联接或符号链接，下载回到原来的位置，准备仍可使用所选文件夹。界面会写明这次仍用原来的位置，不在启动时弹窗。连接、安装和状态查看不依赖这个选择。设置写在原来的个人目录，换盘后仍能读到。先前选过的文件夹，以及暂时不能写但仍能读取的文件夹，仍会出现在清理和套件查找里。正在下载时，同一份材料的成品、未完成文件和导入临时文件都不能勾选；锁文件在下载结束后留在磁盘上，不再因此挡住删除。

清理列表每一项包含用途、大小和路径，默认不勾选。只包括下载文件、解包原厂固件、成品镜像、升级分区和驱动解包目录。密钥、连接、日志、备份和刷写记录不列出。正在下载、准备、刷写或结果尚未确认的项不能勾选。Root 刷写完成，以及原版系统写入完成并等待开机时，打开同一窗口，只列出这一次的内容，默认按钮是「不清理」。
