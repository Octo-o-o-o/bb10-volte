# Windows r61 与手机版 0.2.5.0

- Windows 可以另选一个文件夹，存放之后开始的自动下载，以及新的 Root 和原版升级准备。不选择时仍使用原来的位置，连接、安装和状态查看不受影响。
- 选择不抢占主窗口，不搬走已有文件，也不改道已经开始的下载、准备或刷写。所选文件夹缺失、是符号链接或目录联接、位于程序自身目录或个人材料目录内部，或者不能写入时，新的文件回到原来的位置，界面会说明。
- 清理按项勾选，每一项显示用途和大小，默认不勾选。密钥、连接、日志、备份和刷写记录不会列出。正在下载、准备或刷写的项不能勾选。Root 或原版系统写入完成后可以打开同一次的清理窗口，默认不清理；窗口打不开不会改掉已经完成的结果。

手机版仍是 0.2.5.0，没有新的手机载荷。macOS 下载继续固定为封板 r43。本版没有新的通话、短信或数据验收。
