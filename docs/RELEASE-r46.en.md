# Desktop r46 / mobile 0.1.0.46: China Telecom outbound SMS completion fix + automatic BlackBerry status-bar indicator

2026-11-14. macOS remains at **v0.5.0-r43**. This release has no new Mac package.

- Fixes the longstanding China Telecom (`460-03` / `460-11`) outbound SMS-over-IMS issue where sent messages reached the recipient phone while remaining stuck in "Sending..." (`发送中`) locally and blocking subsequent texts: stock `ims_rrm` `ImsEngineSmsMgr::onSmsDeliverySuccess` (`0xdaa5e`) responds to SIP `202 Accepted` by sending only `NOTIFY_SMS_OUTGOING_RP_PDU_STATUS` (`0x1014`), whereas stock `qct_rrm` (`0xe5080..0xe6234`) in 3GPP mode treats `0x1014` as transport acceptance only and waits for `NOTIFY_SMS_INCOMING_RP_PDU` (`0x1015`) carrying a 3GPP `RP-ACK` (`03 <RP-MR>`), which China Telecom's IP-SM-GW never sends as a separate downlink SIP `MESSAGE`. On Telecom `460-03`/`460-11` only, the hash-pinned runtime copy (`telecom_mo_ack`) records the outbound 3GPP MO `RP-DATA` (`0x00`) `RP-MR` at `0x2ee3c6` and, immediately after `0x1014` IPC succeeds at `0xdaae2`/`0xdab44`, emits a local 2-byte 3GPP `RP-ACK` (`03 <RP-MR>`) via stock `0x139084` + `0x11ec60`. Mobile and Unicom keep the prior 2-hook path untouched, and stock `/radio/bin/ims_rrm` remains read-only.
- Automatically lights up the classic 7-dot BlackBerry status-bar icon (between `4G` and the signal bars) via QNX `/pps/system/navigator/status/bb_service?critical` whenever VoLTE is actively registered on LTE (`ims: connected`, `200 OK`, active LTE radio, matching current boot and SIM), with no manual toggle required.
- Automatically extinguishes the icon and restores the clean `@bb_service` baseline when Mobile Network turns off / Airplane Mode turns on, RAT leaves LTE, IMS registration drops, VoLTE stops or restores, the manager exits or crashes (including `SIGKILL`), or the phone restarts. If native BlackBerry Infrastructure already holds `"state":"on"`, the external state is preserved untouched. All indicator I/O is isolated so errors never affect IMS registration, calls or recovery.
- Preserves all **r45** cross-region incoming-call SIP/SDP compatibility fixes (`MediaDialog.EarlySdp=0`, `MediaDialog.Omit200OkSdp=0`) and MT SMS `In-Reply-To` correlation; published r42/r43/r44/r45 service payloads upgrade in place after stopping VoLTE, keeping existing backups and restoration intact.
- Because the indicator reuses the OS BlackBerry Infrastructure status slot as an auxiliary visual cue, lighting alone does not establish call or SMS acceptance. Verified on `SQC100-2` (China Telecom `460-11`) for outbound SMS completion, startup auto-lighting, radio-cycle recovery, and `SIGKILL` kernel cleanup; historical per-model records remain scoped to the versions tested. The Windows EXE still has no Authenticode publisher signature.
