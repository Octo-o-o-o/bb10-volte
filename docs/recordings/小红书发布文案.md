# 标题

黑莓 Q10 又能打 4G 电话了？真机演示

# 正文

抽屉里的老黑莓，我还想继续用。

做了一个开源的 BB10 VoLTE 工具。这段视频用已连接的 Q10，演示连接手机、兼容性检查和查看服务状态；手机已经 Root 并安装好服务。

这次查询到 IMS 注册正常、网络保持 LTE。项目此前已在 Q10 SQN100-3、BB10 10.3.3.3216、北京联通的组合上完成双向短通话和全程 4G 验证，继续使用系统拨号器和自己的 SIM 卡。

其他机型、系统和运营商需要逐台验证；目前仍是实验项目，注册成功也需要继续完成实际通话验收。首次 Root 刷写会清空数据，动手前务必备份。

项目：GitHub / Octo-o-o-o / bb10-volte
