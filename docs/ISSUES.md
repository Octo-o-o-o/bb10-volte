# 提交问题时提供什么

提供机型、BB10版本、运营商MCC/MNC、本项目版本、安装阶段、`status`的非身份字段、错误文字，以及是否影响原有4G。通话问题注明当地时间、呼入或呼出、是否响铃、接听和双向声音。

v0.3.0 请附 GUI 导出的脱敏预检 JSON、所选配置 JSON、是否开启实验试用，以及号码归属省份、使用省份、携号转网/漫游情况。报告包含自动识别的 Q10 / Q20 / Q30、硬件变体、OS 和原生文件指纹。自定义名称不要填写个人信息；仓库保持 Private 期间，只有有仓库访问权限的测试者能直接提交 Issue / PR。

请先审阅内容，再提交公开issue。不要上传 `private/`、Root镜像、SSH密钥、原始SIP日志、IMSI/ICCID/IMEI/PIN、号码或认证字段。固件哈希、阶段、SIP状态码、匿名化事务时序通常足够初步判断。

新增型号支持需要独立原生文件和ABI验证，不能只删除哈希检查。提出支持请求时，先说明固件版本和哪些文件散列不同。
