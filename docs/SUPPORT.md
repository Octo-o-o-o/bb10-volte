# 完成页与自愿支持

Windows 与 macOS 共用完成页。安装 / 更新或启动服务并通过当前服务的 IMS / LTE 注册验证后，显示“恭喜，你的老黑莓重获新生”。注册待确认时不显示；同次操作随后通过“查看服务状态”或重新检查确认注册，也会显示一次。普通启动应用、发现已有服务和重复查看状态不会反复弹出。统一适配必须确认本次开机、当前 SIM、原生 IMS 与 LTE；Passport 额外重启阶段不会提前显示完成。已注册设备也可主动点击“三网自动适配 → 完成与支持”。

页面保留实际通话验收提示。注册成功不等于呼入、呼出、双向声音、全程 4G、拔线与重启复测已通过。

主操作是“完成，去用我的黑莓”，支持区是次要内容：

- 主动展开“我想请你喝杯咖啡”后选择 ¥9.90 / ¥19.90 / ¥29.90 / 自定义金额，再查看支付宝或微信收款码。
- 打开 [GitHub 项目](https://github.com/Octo-o-o-o/bb10-volte)，由用户自行点击 Star。
- 点击“分享给好友”，按当前界面语言复制中文或英文文案，两种语言都附上官网 `https://bb10-volte.octoooo.com/`；由用户粘贴发送。
- 通过 `octoooo@octoooo.com` 联系开发者；可打开邮件客户端或复制地址。

固定页脚显示“OctoLab 出品”（英文为 “Made by OctoLab”），点击打开 [OctoLab 官网](https://octoooo.com/)。

不强制打赏、不检查是否付款、不收集支付信息；没有自动扣款或自动加星。关闭、Esc 和完成按钮都可直接离开。在本次完成后可通过“更多 → 完成与支持”重开页面。

## 接入收款二维码

公开包只收录八张已经核验的二维码展示图，带有白边和 OctoLab 图标。原始收款截图中的个人头像、收款名和其他界面内容不进入 Git、源码 ZIP 或桌面包。

这些展示图来自已完成的界面渲染，沿用 [octoooo.com 的 favicon](https://octoooo.com/site-assets/favicon-64.png)，并逐张离线验证与开发者提供的原收款码内容一致。应用直接加载已核验的像素，不重复缩小或修改二维码。

建议一个支付平台提供四张**收款码**：三个固定金额和一个不固定金额。只接入支付宝或微信即可，同时接入两种则共八张。不要提供付款码、个人加好友码、密钥或商户 API 凭据。

在手机的收款页面，分别设置 **9.90、19.90、29.90** 后保存收款码；再清除金额，保存一张不固定金额的码。应用的“自定义金额”会显示不固定金额的码，由付款人在支付 App 中填写。

文件放在 `assets/support/`：

| 金额 | 支付宝 | 微信 |
| --- | --- | --- |
| ¥9.90 | `alipay-9_90.png` | `wechat-9_90.png` |
| ¥19.90 | `alipay-19_90.png` | `wechat-19_90.png` |
| ¥29.90 | `alipay-29_90.png` | `wechat-29_90.png` |
| 自定义 | `alipay-custom.png` | `wechat-custom.png` |

只提供一张不固定金额的码也能使用。选择预设金额时会明确提示“扫码后手动填写 ¥…”，不会声称二维码已锁定该金额。缺少该平台的码或图片损坏时会显示暂不可用，其他功能照常。

替换收款码时，原始截图仅留在本机。公开资源应为去除收款名和个人头像后的二维码展示图，保留白边、使用 OctoLab 图标，尺寸不超过 264 × 264，并验证原码、公开资源和界面实际显示三者的解码内容一致。不得重绘二维码模块。离线解码不能代替支付 App 中对收款人和金额的确认；测试无需实际转账。

八个明确命名的图片会自动进入源码 ZIP、Windows EXE 和 macOS DMG 的资源清单；目录中其他图片不会进入发布包。缺少收款码时不放示例或伪造支付码。替换图片后须重新构建并核验发布包。
