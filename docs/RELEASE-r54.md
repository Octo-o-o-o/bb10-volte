# Windows r54 与手机版 0.2.0.0

- **手机版 0.2.0.0 交互与文案精简**：移除首页多余副标题和常驻“通话检查（可选）”次按钮；管理页将低频维护项（设备详情、离线更新包、回滚、设备适配报告、实验适配）折叠进默认收起的「展开高级维护」，并将刷新移入底部操作栏，大幅精简高频中英文提示。
- **免拷 `result.json` 直接验证连接**：手机版授权完成后直接显示 8 位校验码（`XXXX-XXXX`）与完整 SHA-256 指纹（终端备用模式同步打印）；电脑版新增「直接验证连接（免拷结果）」，通过 USB 读取主机公钥并弹窗核对一致后固定 `known_hosts`（保留 `StrictHostKeyChecking yes`、多 USB 设备阻断和 `result.json` 备用导入）。手机版自动读取 `Downloads` 请求同时兼容重命名后缀与未配对优先去重。
- **网盘固件导入与分流提效**：首次 Root 与系统升级窗口支持自动扫描常用下载目录（`Downloads`、桌面、`BaiduNetdiskDownload`）、选文件后自动校验导入、显示目标固件大小与缓存提示，并在复制前秒级拦截误选 `.exe`、未下完或错选机型的文件。主界面突出「安装手机应用」入口，连接弹窗新增「只在手机上使用 VoLTE」与「另存内置安装包（.bar）…」。
- **合并 KT 450-08 实验性 ISIM 试测脚本**：纳入 opt-in 的 `tools/kt_isim_trial.py` 与 `KT-ISIM-TRIAL-README.md`；默认自动适配仍保持原有安全边界不变。

macOS 下载继续固定为封板 r43。新版按实验版发行。
