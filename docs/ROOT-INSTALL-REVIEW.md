# Root 后的原生安装路线复核

复核日期：2026-11-02（Asia/Shanghai）。本轮读取产品源码、当前验收材料与机主在独立验收会话中的最终反馈，没有操作手机、重新安装、重启或修改无线服务。

## 结论

主推 **Root 就绪 → 原生 BAR → BB10 系统安装服务注册 → 手机应用内备份、启用和恢复**。应用为 Cascades/C++/QML 原生应用，固定应用 ID `com.octolab.bb10volte` 和作者身份用于升级。它不是 Android APK、浏览器捷径或手动复制一个可执行文件来冒充已安装应用。

这是与所用 AutoRoot 环境一致的原生安装路线，适合作为本项目推荐方式。“最标准”没有覆盖所有 Root 方案的官方认证含义。AutoRoot v4 作者明确记录：Root 成功通知后允许未签名 BAR、本地权限 helper、含 `MANIFEST` 与可选 `pkg.bar` 的包格式。来源：[AutoRoot v4 作者文档](https://bb10.root.sx/blog/autoroot-v4)。应用内组件另外验证项目发行者签名；这不等同于 BlackBerry 商店签名。

## 已核对的安装边界

- 可信来源与完整 BAR 校验在首次安装之前进行；包内公钥不能自行证明初始 BAR 的来源。
- 桌面安装助手只把固定完整 BAR 和 manifest 交给既有 AutoRoot 安装器，先复制进 Root 私有任务目录并验哈希。安装只提交一次，结果不明时查询同一任务。
- 成功判据是同一任务的 **SUD 最终 success、实际注册版本以及全部安装文件匹配**。`completed` 文案、解压成功、旧图标或进程退出都不能替代它。
- 安装应用与启用无线服务分开；Root、原件备份、设备/系统/SIM 准入及服务操作保持原有检查。支持页不调用 Root、无线服务或安装助手。
- 有兼容本机 BAR 安装器可以从本机入口安装；没有时使用匹配新版桌面辅助一次。公开 r15 尚无新菜单。终端 bootstrap 保留为有经验用户的替代入口，不把 ZIP 宣称为可点击安装器。
- 重启后先解锁、等 Root 成功通知，再打开应用。原生安装成功、纯手机首装、日常不连电脑是三个需要分别核实的结论。

## 本轮交付边界

官网中英文首页将手机安装指南设为主入口，保留现有桌面下载、精确型号兼容性、试测说明及教程。手机页说明原生安装、条件、结果核对和以上按机型区分的范围。官网说明更新不代表发布新 BAR 或新桌面版本。
