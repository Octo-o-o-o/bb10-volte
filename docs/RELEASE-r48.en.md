# Desktop r48 / mobile 0.1.0.48: 3GPP APN bootstrap & 12-MNC operator-name hardening, QNX runtime guards, and mobile diagnostics

2026-11-15. macOS remains at **v0.5.0-r43**. This release has no new Mac package.

- **Hardens 3GPP OI-suffixed and MME-default APN bootstrap on `0.xml` fallback PLMNs**: `profiles.normalize_apn()` strips 3GPP Operator Identifier suffixes (such as `.mnc008.mcc460.gprs` and `.mnc06.mcc460.gprs`) before matching data and `ims` APNs. When newer SIMs (`460-08`, `460-09`, `460-12`, etc.) map to stock `/etc/carrier/config/0.xml` (or blank) before `cdsc_xml` is active, preflight now permits controlled bootstrap on MME-assigned default APNs (such as `cmiot`) in addition to empty APNs, while verifying `0.xml` SHA-256 / non-symlink safety and preserving `fallback_used` and `original_preloaded_config` provenance in service journals.
- **Extends volatile SE.13 operator-name overlay and numeric ONS fallback across all 12 three-carrier MNCs**: `unified_operator_name.py` expands `/var/run/bb10-volte-se13-override.txt` bind-mount entries (leaving `/base` strictly read-only) and numeric-only `current_ons` display fallback to all 12 commercial ranges across China Mobile (`00`/`02`/`04`/`07`/`08`), China Unicom (`01`/`06`/`09`), and China Telecom (`03`/`05`/`11`/`12`), preserving non-numeric brand strings while cleanly upgrading or restoring `r42`–`r47` (`460|11`-only) overlays.
- **QNX Python 3.2 `IOError` guards and bounded `slog2info` reads**: All phone-side `device/` and `mobile/runtime/` modules now catch Python 3.2's distinct `IOError` alongside `OSError`; `service.collect_vpn_evidence()` replaces unbounded `slog2info -b ims_rrm` subprocess reads with an 8-second bounded command; `SQW100-3 -> WINDERMERENA` board mapping, P’9983 `SQK100-1/2` regex validation, and malformed offline update ZIP handling (`invalid_zip_archive`) are hardened.
- **First-tap mobile SIM rejection clarity, cold-reopen caching, and BAR asset hygiene**: The native phone app now surfaces specific explanations for China Broadnet `460-15`, ISIM-bearing 5G USIMs, downloaded OTA carrier overrides, and unrecognized home PLMNs on both the first activation tap and cold reopen (alongside `waiting_sms` state caching). `package_mobile.py` cleans and strictly audits `runtime`, `payload`, `profiles`, and `materials` BAR directories so stale unsigned files can never enter a release BAR.
- **Bilingual desktop, built-in AI Skill, website, and documentation alignment**: Fixes offline pairing response host-key verification fields, desktop recovery hints, and English translation coverage; updates `.agents/skills/bb10-volte`, `ai_skill.py`, and bilingual website/docs while retaining `r46` Telecom outbound SMS completion (`telecom_mo_ack`) + BlackBerry status-bar icon and `r47` 12-MNC admission + Passport Telecom incoming-audio fixes.
- Published `r42`–`r47` service payloads upgrade in place after stopping VoLTE, keeping existing backups and restoration intact. No physical phone was connected during this release; regional and per-suffix two-way call, SMS, and standby verification still require handset testing, and historical records remain scoped to their tested versions. The Windows EXE still has no Authenticode publisher signature.
