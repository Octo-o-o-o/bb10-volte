# Windows r57 and mobile 0.2.2.0

- **Complete legacy `/var/rootdata/q10_volte` auto-migration across all 16 catalog variants**: Verified standard `q10-unicom-volte-v1` installations now migrate automatically across all 16 Q10, Classic (Q20), Passport, and P’9983 catalog variants instead of deadlocking on `unvalidated_legacy_installation`. Foreign variant directories, multi-directory collisions, interrupted installs (`install-transaction.json`), tampered files, and unfinished experimental journals continue to fail closed with explicit codes. Adds `r55` / `0.2.1.0` to `PREVIOUS_PAYLOADS` for safe in-place updates.
- **Close five LTE-only rollback gaps & error-masking bugs**: `unified_service.restore()` now releases owned LTE-only and network-selection overrides across `native_configured` failures and `cleanup_required` aborts; `unified_dca.restore_original()` and `set_network_lock()` isolate failures so `restore_lte_mode()` is never skipped; `reconcile()` and `disable` clean journal state in `finally` and release radio locks; fixes `scan_mode_rejected` classification and expands error codes (`ims_apn_timeout`, `voice_policy_failed`, etc.); fixes `worker.py` hiding `cleanup_required` behind `disabled` and `AutoCarrierWindow` overwriting failure guidance with `sim_not_ready`, and exposes a direct “Disable automatic setup” primary action in the main window on unified errors.
- **Root-cause fixes for Windows driver installation, 32-bit ANSI autoloader paths, and flash-lock safety**: `install_usb_drivers.ps1` now treats `pnputil` exit code `259` (device not yet in Bootrom mode) as staged success so the `BlackBerry Device Manager` MSI always runs, accepts MSI `1638` when already present, and writes redacted `driver-install-result.json` (distinguishing UAC cancel, running conflicting processes, and preparation errors). Windows flashing disables Console QuickEdit click-to-freeze, stages pure-ASCII launch paths and `TEMP`/`TMP` for 32-bit ANSI `cap.exe`, logs launch errors (`launch_error`) and unterminated status/password prefixes across both Root and stock upgrade flashers, and uses a bounded failure pause. `inspect_flash_lock()` inspects all stages (so a Stage-2 pre-write failure never hides a Stage-1 OS write), leaves missing receipts as unknown (`None`), checks process creation time plus live child `flash-active.json`, and Windows ACL hardening now uses pure-ASCII SIDs (`*S-1-...`) instead of localized usernames.
- **Desktop UX & guide alignment**: Fixes `FirmwareDialog` `stage = None` unlock typo, adds a direct Windows driver install button, Bootrom (`RimUsb`) driver preflight status, and live history refresh; adds a direct “Open automatic carrier setup” action for uninstalled Passport devices; adds the “Problem / feedback” bar to Mobile App Install; and updates in-app `docs/GUI.md` and reference guides to match the 16-variant unified workflow.

This is an experimental release. The macOS download remains frozen at r43.
