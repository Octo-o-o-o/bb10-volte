[English](TELECOM-PORT.en.md)

## Q20 的工作参数

电信实际 SIM 为 460-11，原厂 XML 446，散列 `d94f9b7eaa664a9ac496475e706bb837c364635400dd1af9a79608337d57f407`。普通数据保持原厂 `ctnet`，IMS 为 `ims`、IPv4v6、域 `ims.mnc011.mcc460.3gppnetwork.org`。通过原生 DCA 设置 `ue_usage_setting::data_centric`，回读 EFS 为 1，再调用已验证的原生 RadioControl IMS 优先接口，使语音策略 EFS 为 3 并重载 modem。单独改临时 NAS 选项、单独设置语音域或仅写 UE1 而不重载均未在本轮恢复数据。

手机 `/var/q20_volte` 使用独立状态、日志、原生临时副本和开机入口。旧 Root 没有 `/tmp/root.done`；用 `/dev/shmem` 随机标识区分开机周期。开机入口在旧 Term49 安装等待之前。停止时恢复本工具的配置和原始 UE/语音策略，保留软件提供器直到菜单正常重启完成收尾，不在线卸载提供器。

App 检测到该目录后先校验固定清单和每个文件，再调用旧 Root 适配。它不覆盖这台已经工作的服务，也不把更换 Root 作为维护前提。当前清单限本次电信适配；原生文件、载荷或 profile 有变化时需要重新验明版本。

## Q10 手动移植

新增档案 [china-telecom-46011.json](../profiles/china-telecom-46011.json) 明确选择 `lte_attach=telecom_data_centric_v1`。旧电信 03/11 模板和旧档案的规范化字节保持原样；这个新流程不适用于 460-03 或其他 APN。

1. 仍检查准确机型、OS/ABI、全部原生散列、当前 USIM、运营商原厂数据配置、无并行 IMS/VPN、原始语音策略和无覆盖配置。
2. 额外检查 qct_rrm、DCA 固定散列、UE 原值 0，四份 DCA 原文必须为空或只有已知对象头。未知原文保留并拒绝应用。
3. 安装阶段只保存原始文件、inode/权限/所有者及计划。电脑逐份复制并校验原文和计划，回传严格布尔备份回执后才允许启动。
4. 手机端手动启动先应用 UE1 和 IMS 优先，观察 modem 重载、同一张 SIM 和正常 LTE 数据。原核心 IMS 配置入口继续要求 LTE/数据就绪；超时或换卡先回退，不能把紧急服务当作成功。
5. 停止或失败时恢复每份原文，并显式发布 voice_centric 使原生 UE 回到 0，再恢复原来的缺失字段状态。一个发布失败仍继续做源文件和策略的恢复核验。保留手机和电脑备份；未知/并发改动需要人工检查。

此端口没有 Q10 电信实机通话及重启证据，保持 `autostart=false`。不能把 Q10 联通已有验收等同于 Q10 电信通过，也不能把同散列直接当作 Q30 生命周期通过。

## 朋友记录带来的改进

朋友记录的关键线索是：Carrier ID 为 446 时，`cdsc_xml` 曾指向旧的 `carrier-339-volte.xml`。改名停用旧 339/36 文件并重启后，他报告业务恢复；记录也明确没有取得最终加载路径，具体因果仍待补证。

本机只读复查确认，选中的 `/var/q20_volte/runtime/carrier/36-ims.xml` 内部 CarrierID 为 446，普通数据 APN 为 ctnet；文件名中的 36 是历史名称。App 同时核对选择路径、由当前原厂模板生成的预期内容和 journal 的拥有散列，不能仅看 Carrier ID 或文件名。既有安装前检查也继续拦截其他工具遗留的数据配置覆盖，不替用户批量改名或删除。

朋友的 IMS 配置为 AlwaysOn=false、DisableDAD=true、RequestSignallingBearerViaPCO=true；当前成功配置为 AlwaysOn=true，后两项未设置。两者都有成功报告，尚无逐项对照证据支持替换当前值。朋友的短信结果独立保存，不计入本机验收。

公开证据见 [Q20 验收](../materials/q20-device-validation-2026-10-30.json)、[电信研究](../materials/q20-telecom-research-2026-10-30.json)、[朋友记录对照](../materials/q20-peer-telecom-comparison-2026-10-31.json)和 [Root-v2 复现工具](../experiments/q20_autoroot_v2/README.md)。原始 SIP、SIM 派生身份、SSH 材料和完整手机备份只留在私有目录。
