# r49 / 手机版 0.1.0.49

Windows 与手机版更新；macOS 继续封板于 v0.5.0-r43。

## 变化

- 开机先等待系统搜网，超时后继续监听网络状态；同卡且完整恢复、尚未使用原生 IMS 资源的前置失败可安全重试。
- 保留原始射频恢复记录，提供显式、可撤销的手动选网辅助；补齐启动交接尚无 IMS 日志时的停用恢复。
- 动态 USB 地址继续校验原主机密钥；手机端区分组件升级与激活，增加脱敏频段、选网和漫游诊断。
- 新增来电拒接的离线分析与原生回归测试。反复来电界面的反馈尚未复现，不能宣称已修复；本轮没有新增真机验收。

## 升级与恢复

保留 r48 的三网 12 号段准入、APN 引导、短信和语音路径。r42–r48 后台通过原始备份与载荷核验后可原地升级：在应用中检查状态，按提示停用、更新和正常重启；不要删除启动令牌或强卸载加密提供器。新版 BAR 更新界面与运行组件；仅更新组件 ZIP 不会替换原生界面。

手动选网仅在明确请求后使用 `volte lock-network`／`unlock-network`，要求正确身份、匹配原生文件、当前 SIM、备份及空闲无线资源。用户已有 MANUAL 设置保持不变。IMS 连接不能替代双向通话、声音、短信和移动数据验收。

## 核验范围

本版执行完整 Python 回归、原生 ARM/Thumb 矩阵、公开文件与隐私检查、手机签名资产及 BAR 回读、Windows EXE 离线自检和中英文官网静态／浏览器检查；最终流水线结果见同标签 GitHub Actions。原始设备、三网和生命周期证据沿用其真实版本范围。

网络等待、射频模式协调、同卡重试、手动选网及动态 USB 的新版真机效果仍待实测；不宣称测得续航改善。来电界面问题的现有线索和反证见[调查记录](CALL-REJECTION-INVESTIGATION-2026-11-17.md)，操作边界见[等网与选网指南](NETWORK-RESILIENCE.md)。Windows EXE 尚无 Authenticode 发布者签名。
