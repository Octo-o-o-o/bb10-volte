# 桌面 r43：Windows 卡顿与磁盘占用修复

2026-11-09。手机版保持 **0.1.0.43**，本次没有修改手机端载荷或新增实机验收。

- **Windows 界面卡顿**：改用内置控件绘制，避开小型半透明图片大量平铺造成的事件循环阻塞。打开页面、切换标签和缩放窗口的本机对照从秒级停顿恢复到几十毫秒；不同电脑仍应按实际使用验证。进度动画从每 12 ms 改为默认 50 ms 刷新。
- **准备材料复用**：相同型号、平台和配方的完整 Root 材料重新核验后复用。固件重复导入、驱动准备也避免重复复制；并发准备会等待或提示，不另建一份。
- **磁盘清理**：清理本工具失败构建留下的大文件和冗余下载片段；保留个人密钥、连接文件、备份、日志与刷写状态。正在刷写或结果不明的材料仍保留。新增应用内“存储位置与磁盘清理”入口。
- Windows、macOS 通用包和源码同步；Mac 继续使用原有圆角主题。官网更新桌面下载，同时将简短展示文案与完整适配证据分开，保留原型号结果。

升级时退出旧桌面程序，再使用新 EXE 或替换 Mac 应用。**不需要因为这次桌面更新而重新刷机、Root、激活或安装手机版。** 个人连接与恢复材料仍在原目录。手机卡顿、续航或电信短信状态不属于本次修复；部分电信短信已送达但仍显示“发送中”，请勿重复发送。

详见[绘制问题与对照](WINDOWS-UI-PERFORMANCE.md)、[存储位置和手动清理](DISK-CLEANUP.md)。新增回归覆盖 Windows 三种缩放比例下的真实绘制、切页和动画，EXE 自检也测量实际事件循环响应。发布包、CI、Mac 签名公证与公开下载校验结果记录在本次发行材料中；离线检查不作为新增手机通话验收。Windows EXE 仍未使用 Authenticode 发布者签名。
