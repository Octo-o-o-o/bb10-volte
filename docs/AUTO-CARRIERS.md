# 三网自动适配

[English](AUTO-CARRIERS.en.md) · [Windows](WINDOWS-EXE.md) · [macOS](MACOS.md)

当前实验版为 **0.5.0-r8**。Windows 与 Mac 使用同一安装流程和手机载荷；配置在手机正常开机时按当前 SIM 生成，后续关机换卡无需电脑或重新刷机。

## 范围与当前验收

范围为 **SQN100-3、SQC100-2、SQW100-4，OS 10.3.3.3216**，移动 **460-00**、联通 **460-01**、电信 **460-11** 的 USIM 无 ISIM 路线。需要对应机型已 Root、可信 SSH 和可用的运营商服务。自动适配入口不执行首次 Root 刷写。

当前 **9/9** 个组合通过功能验收：

| --- | --- | --- | --- |
| Q10 SQN100-3 | 通过 (r7) | 通过 (r7) | 通过 (r8) |
| Q20 SQC100-2 | 通过 (r7) | 通过 (r8) | 通过 (r7) |
| Passport SQW100-4 | 通过 (r8) | 通过 (r7) | 通过 (r7) |

[结构化验收记录](../materials/unified-carrier-acceptance.json)标明每项实际载荷版本、正常开机、断开 USB、换卡和通话证据。安装后当前卡的通话与不连电脑换卡分别记录。换卡测试由机主检查接通计时、双向声音、首次呼出及全程 LTE，接回后核对当前开机的 SIM、配置和原生进程。手机环形日志可能只剩末段信令；完整双向 SIP 记录与机主确认的通话分别标明。通话后的单次 LTE 快照不代表全程连续采样。

本轮 Mac 实机 USB 验收由机主暂缓。历史 Mac 连接记录、软件自检、签名和公证分别记录，不能替代当前版本的手机连接验收。其他硬件变体、系统、MNC、SIM 类型、地区、漫游及长期稳定性仍待验证。

## 首次安装与以后换卡

1. 用 USB 连接并解锁一台已 Root 的目标手机，选择其可信连接配置，进入“三网自动适配”，核对准确型号和当前 SIM。
2. 点击“备份并安装自动适配”。程序先保存并下载校验原始入网配置和旧开机入口，再迁移旧管理器。原始备份和旧载荷保留。
3. 用手机电源菜单正常重启，解锁后等待约 3–5 分钟，点击“已重启，重新检查”。程序确认本次开机的运营商、IMS 注册和 LTE 后显示“本次开机注册成功，请验收通话”，再断开 USB 验证系统拨号器的呼入、呼出和双向声音。
4. 后续先正常关机，再更换 SIM 并正常开机。配置由手机自动选择；热插卡不属于已验收流程。
5. Passport 首次改变电信入网策略后，先等待约 5 分钟，再正常重启一次，让基带在开机时采用已保存的策略。进入和离开电信都可能需要这一步，飞行模式不能替代正常重启。

Windows 和 Mac 的主窗口及“三网自动适配”窗口会将这一阶段显示为“还需一次正常重启，适配尚未完成”，说明原因并保留“已重启，重新检查”按钮。尚在自动启动时显示等待状态，不会反复要求重启；只有本次开机的注册和 LTE 均确认后才显示成功。重启断开 USB 数据连接时可点击“重新检查连接”，重新打开程序也会按手机当前状态继续流程，无需重新安装。文件更新后若自动启动仍关闭，程序会先提示“启用自动适配”。

## 本机号码显示

r8 将 Q20 已使用的号码显示补全扩展到 Q10 和 Passport。号码只取自当前开机、当前原生进程、当前 SIM 的 IMS REGISTER 200 认证结果，写入拨号器的号码显示缓存；SIM 记录、呼叫身份和无线设置不由这一功能改写。

没有唯一的认证号码时保留当前显示状态。已有独立号码值会保留；服务自己填写的旧 SIM 号码在换卡后不会被当成新卡的恢复原值。写入中断后保留原始值，并在同次开机的同一 SIM 上继续或恢复。真实号码仅保存在手机私有状态，桌面检查仅报告是否匹配和是否为空。号码正确、运营商名称或 4G 图标均需要与实际通话结果分别验收。

## 升级与停用

已装已识别旧载荷的手机可检查更新。停止旧管理器并恢复设置后，先正常重启清除旧运行组件，再安装、校验和启用新版；随后正常重启启动新版。程序备份旧 Python 文件并下载校验，最后才提交新载荷清单。原生 IMS 每次正常开机只启动一次，软件加密提供器保留到正常重启。

停止自动适配后可在同一窗口重新启用，待恢复结束后正常重启。主界面优先识别统一服务，避免再次激活迁移前的独立适配。进行中的通话、未知原厂文件、无有效备份回执或独立配置变化会阻止相关写入。

r7 的 Q10 移动持续驻网修正沿用到 r8；r8 的手机代码变化限于号码显示、恢复与更新支持，入网策略和 IMS 引擎保持 r7 的内容。短通话及已有约 20 分钟的驻网观察不代表长期稳定性验收。
