# 三网自动适配候选

桌面 `0.5.0-r2` 的“三网自动适配”入口在 Windows 与 macOS 使用同一安装流程和手机载荷。它接替旧版本的单运营商配置，首次安装后在手机正常开机时读取当前 SIM，生成本卡的 IMS 身份、运营商域和数据配置；后续换卡无需电脑或重新刷机。

当前范围为 **SQN100-3、SQC100-2、SQW100-4，OS 10.3.3.3216**，移动 **460-00**、联通 **460-01**、电信 **460-11** 的 USIM 无 ISIM 路线。其他变体、系统、MNC 和 SIM 类型不回退套用现有配置。手机需要已完成对应机型的 Root 和可信 SSH 连接；本入口不执行清空数据的首次 Root 刷写。

这是新的统一候选，原有分机型试验的成功记录不能替代本候选的换卡验收。安装、正常重启、三网轮换、USB 断开、呼入/呼出和双向声音分别记录。Q10 移动尚无此前的完整实机验收；Q20 移动此前重启后的首次去电曾失败，随后重拨成功，仍需稳定性复测。长通话和长期稳定性不由短通话推定。

2026-10-31：统一载荷已在 Q20 移动卡上完成安装、正常重启自动注册和拔 USB 双向短通话。两次接通约 4.2 秒与 4.8 秒，首次去电直接接通，机主确认双向声音和 LTE 正常；151 次采样均为 LTE。30 秒以上通话和跨运营商换卡尚待补测。Passport 已安装，重启与通话待验收；Q10 正等待 USB 数据连接。

## 使用

1. 连接目标手机，进入“三网自动适配”，检查准确型号和当前 SIM。
2. 点击“备份并安装自动适配”。程序先下载并校验四份原始入网配置，以及旧 Root 开机入口的备份，再停用旧管理器并安装新入口。旧载荷和验收记录保留。
3. 使用手机电源菜单正常重启。等待正常 LTE 与 IMS 注册后，手动检查呼入、呼出、双向声音和全程 LTE。
4. 后续关机换卡，再正常开机。新配置在手机内生成，无需再次连接电脑。不要将热插卡后的瞬时状态当作换卡完成。
5. 停用后可在同一窗口重新“启用自动适配”，待原管理器恢复完成后启用，再正常重启。主界面会优先识别统一服务，防止重新激活迁移前的独立适配。
6. Passport 的电信数据优先策略需要在基带正常开机时生效；首次改变这一策略后可能还需再正常重启一次。桌面状态显示“运营商入网策略已保存，请再正常重启一次”时执行该步骤。飞行模式不能替代这次重启。

## 已整合的行为

- 移动使用 Q20/Passport 已验证的 EarlySdp=0 临时 IMS 副本，原厂二进制不覆盖；非移动仍使用原修正。
- 电信入网设置使用已核验的 DCA 发布路径及原始文件备份；换回其他运营商时恢复原策略。
- 软件加密提供器保留到正常重启，不在停用或换卡时卸载。每次开机只允许一次原生 IMS 启动，避免重复启动造成承载异常。
- SIM 身份、号码和信令仅留在手机私有目录。Q20 本机号码仅由当前原生 IMS 的 REGISTER 200 认证结果补全；电信名称修正只处理当前本地 460-11 正常 LTE。
- 固定程序清单与随 SIM 变化的配置分开校验。没有有效备份回执、未知原厂散列、独立配置修改或进行中的通话时，相关写入停止。

设备注册成功不等于通话验收成功。请保留检查结果，并在统一候选完成九种组合与换卡过程之前维持候选标记。
