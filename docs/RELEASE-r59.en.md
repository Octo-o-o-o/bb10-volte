# Windows r59 and mobile 0.2.4.0

- **Offline global overseas carrier catalog & desktop/mobile opt-in editor (zero regression / zero clutter for Mainland China)**: Adds an offline Apache-2.0 reference catalog of 287 non-`460` carriers derived from AOSP (`materials/overseas-carriers.json`, with country/region, IMS APN, IP family, and data APNs, honestly labeled `untested` on BB10 hardware, and bundled with full Apache-2.0 license and NOTICE attribution across source, Windows EXE, and mobile BAR/update ZIP). Mainland China (`460-*`) SIMs keep byte-identical XML/PPS and the exact 1-click UI with zero overseas banners. Non-`460` SIMs (or active trials) unlock a management-lock-protected overseas configuration flow across Desktop GUI, native Mobile QML, and headless CLI (`tools/overseas_carrier.py`).
- **Schema 2 overseas trial engine & verified stock `0.xml` fallback**: Supports single or multi-carrier configurations, `'auto'` data APN resolution, optional `stock_config` and `ue_usage` (`data_centric` opt-in), optional IMS XML flags (`AlwaysOn`, `RequestSignallingBearerViaPCO`, `DisableDAD`), and allowlisted `IR.92` (`UsePreconditions`, `SMS_Format`, `amr_modeset_list`, `amrwb_modeset_list`) and `ims` PPS fields (`SilentRedial`, `SIP_Timer_CSFB`) with full journaled backup/restore. Explicit overseas opt-in can safely fall back from stale legacy numeric carrier XMLs to SHA-256-verified stock `0.xml`, accepts non-IMS v3 CDSC overlays without modifying them, and handles carrier XMLs that initially have zero IMS blocks.
- **Clean-room P-CSCF host route sync & lifecycle cleanup**: Addresses `ims_rrm` non-root `Permission denied` route socket errors by incrementally parsing owned `native.log` entries, validating every gateway against live `/pps/services/networking/all/interfaces/msm*` cellular interfaces (rejecting loopback, link-local, USB, and Wi-Fi gateways), installing verified host routes as Root via `/sbin/route`, tracking owned routes in the journal without claiming `File exists` routes, sweeping stale gateways, and cleanly removing owned routes on stop without touching routes across reboots. Registers `r56/r57/r58` in `PREVIOUS_PAYLOADS` for safe in-place updates.
- **Read-only LTE disabled-band diagnostic, exact IPv6 redaction & Windows cleanup hardening**: Adds a strict non-false-positive `lte_bands_disabled` read-only diagnostic (never touches baseband NV); upgrades IPv6 log/feedback scrubbing in both `device/service.py` and `tools/feedback.py` using `socket.inet_pton(AF_INET6)` so compressed, trailing-colon, prefixed, and zone-scoped IPv6 literals are completely redacted while preserving VPN UIDs and technical tokens; includes Windows `prepare_driver_kit` transient `PermissionError` cleanup hardening.

This is an experimental release; overseas reference presets and new runtime paths have not completed physical hardware acceptance. The macOS download remains frozen at r43.
