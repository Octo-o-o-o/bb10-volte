# 兼容性预检与客户信息

[English](COMPATIBILITY.en.md)

0.3.3 在预检报告中加入按硬件、OS 和实际 MCC/MNC 精确匹配的社区证据，以及有限枚举的只读来电诊断。新增证据不代表本工具已验收。Passport 自动操作暂缓，见[社区研究](COMMUNITY-RESEARCH.md)。

v0.3.0 将机型识别、运营商配置和原生补丁兼容性分开判断。GUI、CLI 和手机安装器共用 `device/compatibility.py`。预检不证明运营商已经给该卡开通 IMS，也不代替真实通话。

| 组合 | 自动结论 | 实机证据 |
|---|---|---|
| Q10 SQN100-3 / OS 10.3.3.3216 / 联通 460-01 / USIM 无 ISIM / 3gnet / LTE / 原生哈希匹配 | 符合当前适配条件；还需安装前状态通过 | 北京单机双向短通话及正常重启 |
| 其他省份联通，且上述条件全部相同 | 可进入逐台试验验收；MCC/MNC 不能确定归属省份 | 尚无跨省实机结果 |
| Classic（Q20，SQC100-*）、其他 Q10 变体 | **未实测适配 · 可实验试用**；明确勾选试用且全部技术检查通过后允许安装 | 本工具尚无对应手机验收；Q20 社区记录单独标注来源 |
| Passport（Q30，SQW100-*） | **恢复策略待验证**；暂缓自动安装、更新、启动及恢复，试用开关不能绕过 | 社区贡献者报告双向通话，也报告提供器停用导致网络栈重启；尚未独立复现 |
| 联通其他 MNC、移动、电信或自定义配置 | 选择匹配模板或编辑参数；勾选试用且全部技术检查通过后允许安装 | 公开资料模板，未实测 |
| ISIM、未知 SIM 类型、身份格式不同 | 当前 USIM 实现需另行适配，禁止安装 | 未验证 |
| 未知或冲突的机型身份、OS 不同、任一原生哈希不符 | 禁止安装，可导出报告供适配 | 试用开关不能绕过 |
| SIM、Root、LTE、数据 APN 未就绪，或已有服务未恢复 | 处理后重新预检 | 不覆盖现场 |

电脑平台另按连接链路验收：2026-10-28，Mac mini / Apple M6 / macOS 27.2 与上述 Q10 组合通过内置 CDC-NCM USB 网络、严格 SSH/有效 UID 0、既有服务读取、机主手动双向声音/LTE 及 USB 重连；没有安装额外驱动。仅此单机组合，Intel、其他 macOS/USB 模式、首次授权写入、Mac 初次 Root 和本轮手机重启未测。发布 r5 的首次向导有已知误报，源码修复与发布包分开记录。见[Mac 使用说明](MACOS.md)和[脱敏实测记录](../materials/macos-device-validation-2026-10-28.json)。

机型名称和硬件变体来自 `/pps/services/deviceproperties`，系统版本来自 `/etc/os.version`。可用变体前缀识别名称缺失的手机；名称与变体冲突则拒绝。Q20 / Q30 对应 Classic / Passport，官方型号例见 [Classic SQC100-2 手册](https://www.att.com/support_static_files/manuals/BlackBerry_Classic_SQC100-2.pdf)和 [Passport SQW100-3 手册](https://www.att.com/support_static_files/manuals/BlackBerry_Passport_SQW100-3.pdf)。识别成功不表示射频、驱动和 IMS 已验证。

试用始终要求 **OS 10.3.3.3216、Root、QNX ARM32、4 个原生文件 SHA-256 完全匹配**、实际 SIM 与配置一致、原厂数据配置可核验、LTE 与数据 APN 在线，以及安装前无冲突。不同文件不能靠编辑 JSON 或开启试用跳过。原生引擎为 `qnx-arm32-os3216-native-v1`；新增哈希或系统版本需要代码适配和实机验收。

**仓库的固件下载和 Root 镜像构建材料仍仅对应 Q10。Q20 / Q30 测试者必须准备其自身机型适用的 Root 与 SSH，不得使用本仓库的 Q10 镜像刷写。** 本次扩展的是已 Root 手机上的识别和 VoLTE 试用流程。

P-CSCF 由 IMS APN 的 PCO 获取，没有硬编码北京地址。省份不是代码门槛，但开通情况、终端策略、频段、APN、漫游和现场网络可能影响结果。见 [运营商配置](PROFILES.md) 和 [资料调研](CARRIER-RESEARCH.md)。

客户提供的信息：

1. 型号、变体、完整 OS、已有 Root 与 SSH 情况；预检会自动核对。
2. 运营商、号码归属省份、当前使用省份、携号转网和漫游情况。不需要完整手机号。
3. 同一张卡在已支持 VoLTE 的手机上能否保持 4G 完成双向通话。
4. 所选配置 JSON 和脱敏预检报告，包含机型、原生文件指纹、MCC/MNC 与检查结果。
5. 安装后的失败阶段或逐项通话验收结果；原始日志留在本地。

报告不自动收集完整 IMSI/IMEI/ICCID、PIN、SIM 密钥、认证材料或 SSH 密钥。身份只在手机本地判断和派生；不要把个人信息填写进自定义名称。改配置会使已有预检失效，更新前需先停用恢复。欢迎其他系统版本、机型和运营商的 Issue / PR，详见 [问题说明](ISSUES.md)。

未验收机型／运营商组合还必须关闭 runtime.autostart，采用手动启动；试用开关不能绕过。作者补充了自启动卡开机动画的反馈，当前 Q10 已验收基线保留自动启动。
