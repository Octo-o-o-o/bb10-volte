# 兼容性预检与客户信息

[English](COMPATIBILITY.en.md)

固定适配档案：`q10-sqn100-3-os3216-unicom01-usim-v1`。检查逻辑位于 `device/compatibility.py`，GUI、CLI 和手机安装器共用。仅报告符合条件，不自动证明运营商已给该卡开通 IMS 或通话可靠性。

| 组合 | 自动结论 | 实机证据 |
|---|---|---|
| Q10 SQN100-3 / OS 10.3.3.3216 / 联通 460-01 / USIM 无 ISIM / 3gnet / LTE / 原生哈希匹配 | 符合当前适配条件；还需安装前状态通过 | 北京单机双向短通话及正常重启 |
| 其他省份联通，且上述条件全部相同 | 可进入试验验收；无法从 MCC/MNC 判断归属省份 | 尚无跨省实机结果 |
| 联通其他 MNC、带 ISIM 或身份布局不同 | 需要适配，禁止安装 | 未验证 |
| 中国移动、中国电信及其他运营商 | 需要适配，禁止安装 | 未验证 |
| 其他机型、Q10 变体、OS 或原生文件哈希 | 不支持当前档案，禁止安装 | 未验证 |
| SIM、Root、LTE 或 3gnet 未就绪 | 等待处理，禁止安装 | 就绪后重新预检 |

配置没有硬编码北京 P-CSCF 地址，P-CSCF 由 IMS APN 的 PCO 获取。因此省份本身不是代码限制，但 IMS 开通、终端策略、APN、漫游和现场网络仍可能影响结果。工具不会根据省份自动生成运营商配置。

客户预先提供：

1. 手机型号、变体和完整 OS 版本；已有 Root 和 SSH 的情况。自动预检会再次读取核对。
2. 运营商、号码归属省份、当前使用省份，是否携号转网或漫游。这里只需要描述，不要提交完整手机号。
3. 这张卡在其他支持 VoLTE 的手机上，是否能保持 4G 完成双向通话。
4. 脱敏预检 JSON。SIM 类型、MCC/MNC、LTE、APN 等由手机自动读取，不要求客户手抄 IMSI。
5. 安装后逐项验收结果及失败阶段。先提交脱敏报告；原始日志留在本地，单独审查后才考虑分享。

预检不收集完整 IMSI/IMEI/ICCID、PIN、SIM 密钥、认证材料或 SSH 密钥。身份格式只在手机本地转换为是否匹配的布尔值。一个发布包适配档案不能用不同客户的身份文件混装。

安装前还要求没有未知 IMS/VPN/软件算法提供器、原语音策略为 0、无外部覆盖配置。旧版完整安装支持在停用恢复后更新；中断、内容改变或未知目录会阻止覆盖。

新增地区和运营商支持应通过新的版本、代码审查、对应原生哈希和实机验收扩展。欢迎其他版本的问题报告与 PR；请遵循 [问题说明](ISSUES.md)。
