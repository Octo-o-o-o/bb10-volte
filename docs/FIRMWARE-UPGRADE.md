# 手机系统升级与型号匹配

[English](FIRMWARE-UPGRADE.en.md) · [首次使用](FIRST-RUN.md) · [连接恢复](RECOVER-CONNECTION.md)

`0.5.0-r13` 提供原版系统升级流程，整合 Q10、Classic / Q20、Passport / Q30 的个人 Root 镜像准备。当前目标是 **OS 10.3.3.3216**，不是软件发布版本号，也不是“至少这个版本”。程序按数字比较 OS，兼容固件文件名中的 `10.3.03.3216` 写法。

这是需要机主确认的完整固件重刷，会清空手机数据、现有 Root 和授权。准备材料可以自动完成；插上手机不会自动开始刷写。软件测试、固件离线校验和打包验证不代表旧系统真机升级已经通过。候选界面保留该项未验收提示。

## 版本如何处理

| 检测结果 | 行为 |
| --- | --- |
| 低于 10.3.3.3216 | 连接页进入系统升级，匹配原版固件；禁止直接刷 Root |
| 等于 10.3.3.3216 | 不重复升级；按实际 Root / 连接状态继续 |
| 高于 10.3.3.3216 | 停止自动处理，不自动降级 |
| 版本缺失、格式不完整或多台设备 | 禁止系统及 Root 刷写，要求重新检测 |

读取的是直接 USB 连接的匿名设备信息。不能仅凭终端截图、Root helper 名称或“权限不足”报错推断 OS 版本。

## 准备与执行

1. 只连接一台手机，解锁并建立 USB 网络。选择“连接帮助 → 查看对应机型的系统升级”；也可从首次使用向导选择“系统升级 / 继续升级记录”。
2. 核对准确型号。Q10 使用 SQN100-1～5 对应固件；Q20 使用 SQC100-1～5 对应固件；Passport 使用 SQW100-1～4 对应固件。检测到的设备优先，手动选项不能覆盖检测结果。VoLTE 实机验收仍仅覆盖记录中的 SQN100-3、SQC100-2、SQW100-4。
3. 点击“准备升级与 Root 材料”。至少留出 **24 GB** 可用空间。应用获取并校验固定来源，生成本次个人密钥和 Root 镜像，同时准备原版系统。也可从固件下载与导入入口先导入原始文件，再回到升级页准备。离线手动选择型号只授权电脑端准备。
4. 完成备份，勾选清空数据确认，再确认显示的机型和旧 OS → 目标 OS。刷写开始前会重新读取设备，状态变化则停止。Windows 运行该型号原版 EXE；Mac 使用已校验的原生工具，先写原版签名 OS，再写对应 radio。密码只在工具窗口输入。
5. 写入结束后等待开机，完成必要的手机设置、解锁并恢复 USB 网络，点击“手机已开机，验证系统版本”。工具退出成功只表示写入阶段完成；读回精确目标 OS 后，才可继续 Root。
6. 点击“系统已验证，继续 Root”，再次核对与确认清空操作。应用复用同次准备的个人镜像，Root 完成后另行验证手机身份和有效 UID 0，再返回 VoLTE 检查。

本流程不提供无损 OTA，不自动接受手机上的首次设置或密码提示。已有正常 Root 且达到基线的手机无需重刷，应使用连接恢复。

## 中断与继续

准备完成、等待开机、已验证 OS 的记录均保存在电脑个人目录。关闭后通过“继续选中的准备记录”恢复；恢复记录不会自动开始刷写，也不会沿用之前的清空确认。

任何工具错误、非零退出、结果缺失、超时或中断都会保留日志和共享刷写锁，禁止再次启动原版或 Root 刷写。窗口关闭不能撤销已写入的数据。不要删除锁、重放终端脚本或盲目重试；应保留当前手机状态及电脑材料，逐项确认原工具是否仍在运行、哪个阶段已完成。

原版系统升级必须完整成功，**不使用 AutoRoot 特有的 Windows OS 退出 73 例外**。Mac 同样必须得到完整的原生写入证据。

## 校验边界

原版 EXE 绑定来源 SHA-256，Mac 拆出的签名 OS / radio 还绑定独立的固定 SHA-256 和大小。字段及绑定见 [stock-upgrade.json](../materials/stock-upgrade.json)。这证明与已固定材料一致，不等于另行取得制造商签名认证。Root 镜像使用每次独立密钥，按同次构建回执、型号、平台和文件散列核验。

下载始终验证 HTTPS 证书和主机名。自带 Python 的 Mac 应用若没有默认 CA，使用 macOS 管理的系统证书；已有 CA 或显式证书配置保持优先，无需用户另行安装 Python 证书。

Q10、Q20、Passport 三份真实原版固件已离线重新拆分并比对。版本、机型、损坏文件、取消、中断、重复执行及 OS 回读均有故障注入测试。旧 OS → 原版系统 → 开机 → Root → 有效连接的真实设备闭环仍须单独验收，不能用现有 VoLTE 九项功能验收替代。
