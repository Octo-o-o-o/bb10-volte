## 0.5.0-r8 · Q10、Passport 本机号码显示 · 2026-11-01

Q10 换联通后通话正常，但拨号器号码为空；原统一服务只在 Q20 调用认证号码补全。r8 将这一流程扩展到三款已支持机型，仍要求当前开机、当前 SIM 和原生进程的 REGISTER 200 认证结果。显示缓存的更新与恢复不会写 SIM 记录或无线设置。

同时修正旧 SIM 号码被误作新卡恢复值的问题，并保留中断写入的原始回滚记录；已正确显示的号码也保存当前认证缓存，避免日志轮转后丢失依据。支持从已识别的 r7 载荷备份升级。入网策略与 IMS 引擎沿用 r7。

Windows／Mac 共用流程增加明确的额外重启阶段、原因和“已重启，重新检查”按钮。主窗口与管理窗口都依据本次开机的状态显示结果；旧注册缓存、仅有 LTE 或刚启用均不会显示注册成功。USB 重连后重新检查，已停用的更新先提示启用，避免反复重启或重复安装。

完整回归运行 474 项，473 项通过、1 项跳过。Q10 联通号码显示已由机主确认正确，r8 断开 USB 呼出接通 48.268 秒，采样均为 LTE；Passport r8 第二次正常启动后已自动完成电信注册。实机通话、换卡与号码显示按实际载荷版本分别记录，最新结果见[验收矩阵](../materials/unified-carrier-acceptance.json)及[统一流程](AUTO-CARRIERS.md)。

2026-11-01 最终验收：九个准确机型／运营商组合在记录的 r7／r8 载荷上通过功能验收，三台现均安装 r8。最后一轮不连电脑换卡后，Q10 电信、Q20 联通、Passport 移动的双向通话均超过接通 35 秒，机主确认声音、LTE 与自己的号码正确，Passport 同时正确显示“中国移动”。Q10 电信只以最后一组为本轮验收；此前对端号码问题另记，不判定本轮首次拨号通过。六项不连电脑换卡与三项初始卡基线分别记录，保留 SIP 计时与机主确认时长的证据区别。本轮 Mac 真实 USB 验收暂缓，打包、自检、签名及公证不替代该项。

中英文官网同步说明一次安装、关机换卡后自动适配、Passport 额外重启、逐项验收范围，并提供同版本 R2 与 GitHub 下载。官网源码纳入本仓库及源码发布包。

## 0.5.0-r7 · Q10 移动持续 LTE 入网策略 · 2026-10-31

r7 验收进展：r6 已通过 Q20 电信和 Passport 联通的正常开机自动注册及拔 USB 双向通话，接通时长分别为 58.3/54.1 秒与 36.9/37.7 秒；各 450 次采样均为 LTE。Q20 更早一次未接通呼出由机主主动取消。Q10 移动 r6 起初注册正常，但随后收到网络拒绝原因 18，基带自动将制式从含 LTE 的 19 改为 3，掉网且无法通话；本轮不计通过。r7 仅为 Q10 移动增加经原始配置备份的 data-centric 入网策略，保持电信既有策略，换回联通时恢复原策略。修正仍待实机复测，九种组合尚未全部通过。Passport 联通的本机号码栏仍为空，单独列为显示限制；不能用号码或 4G 图标代替通话验收。

## 0.5.0-r6 · 开机空闲状态等待 · 2026-10-31

r6 验收进展：Q10 电信 r5 已通过拔 USB 双向 35 秒以上通话；第一轮关机换卡后，机主确认 Q10 移动双向通话正常，日志尚待读取。Q20 换电信和 Passport 换联通均选择了正确运营商，但在 IMS 启动前的空闲检查退出。r6 增加有时限的稳定空闲等待：连续两次确认通话服务、IMS 与 VPN 空闲后才继续，最多等待 180 秒；超时或停止请求不进入新的网络策略写入。修正仍待实机复测，九种组合尚未验收通过。4G 图标和本机号码显示不单独作为语音注册成功证据。

## 0.3.3-r1 · 2026-10-29

本版整合全部本地开发分支。桌面版本为 `0.3.3-r1`，手机端载荷为 `0.3.3`，继续作为实验性预发布提供。

- **连接手机**：用“连接手机 / 连接帮助”引导检查 USB、网络、手机身份、登录授权和有效 Root。可选择原刷机文件夹恢复个人材料，SSH 路径及别名放入高级设置；连接失败不会自动进入首次 Root。
- **继续未完成的操作**：重新打开时复查上次成功连接；保留未完成授权的原密钥、请求编号和步骤，已完成的镜像准备可重新校验后继续。刷写结果不明确时仍暂停。
- **下载恢复**：固定材料支持断点续传、有限重试、大小与速度进度，以及可操作的失败提示。服务器不支持续传时安全重新下载；完成后仍必须通过 SHA-256 校验，失败缓存不会作为有效材料使用。
- **桌面控件**：统一按钮、输入框、下拉框、标签页、进度条和滚动条样式，优化紧凑窗口及向导页面的滚动，保留原生键盘和控件行为。
- **社区研究**：增加有来源和适用范围的社区记录，以及只读来电配置诊断；在“更多 → 社区研究与适配进展”和导出报告中查看。社区案例不等于本项目实机验收。
- **兼容性保护**：未验证的机型或运营商组合要求关闭自动启动并手动启动；Passport 的安装、启动和自动恢复保持暂停，直到提供器生命周期得到验证。实验选项不能绕过该限制。
- **发布整合**：保留此前 Mac 连接诊断、原生 Q10 Root 实验入口、IMS 启动和验收修正；合并历史分支时保留后续修复，更新中英文使用说明。
- **跨平台修复**：修复 Mac 向导内容缩短后的旧滚动范围，为隔离构建补齐 SSL 动态库路径及子进程传递，并显式打包 SSL/crypto 库；公证前先运行不依赖构建环境的离线应用自检。

本次检查覆盖源码回归、公开文件白名单与散列、两平台打包资源和离线应用自检；最终结果以 Release 的验收附件为准。Windows EXE 未做 Authenticode 签名。Mac 包沿用 Developer ID 签名、Apple 公证及附加票据流程。

本次发布不新增手机首刷、持久授权、重启、通话、长时间稳定性或 Intel 实机运行的验收。先前 Q10 / 联通及 Mac r5 的实机记录保留其原有版本和范围，不能代替 `0.3.3` 载荷验收。Q20 / Passport 不可使用 Q10 首刷镜像。
