# r42 / mobile 0.1.0.43

本版整合 r21 以来的本地代码和收机反馈。Q10、Classic/Q20、Passport、P’9983 全部目录型号开放移动 460-00/07、联通 460-01、电信 460-11。按完整后缀显示实测可用、实测有问题、实测未通过和未实测；开放入口不代替实测。最新 SQC100-1 与 SQK100-1 三网结果为机主报告通过。

## 改动

- 主应用内电脑配对，保留原授权。已 Root 手机日常独立使用不需要电脑配对。
- 更稳妥的任务恢复、旧服务升级及换卡处理；启动后的状态和需要处理的消息提示。
- 稳定连接时减少重复检查与写入，使用有界事件等待；没有量测整机耗电改善百分比，不宣称完全零资源占用。
- 保留电信 CTNET 代理修正、短信 ACK 关联及部分冷启动短信忙状态恢复。已有问题场景有修复，不能声称所有型号和网络的重复短信已消失。
- 用户主动安装/启用且确认移动网络关闭时，打开移动网络、核对回执并重新检查 SIM；后台观察不自动开关网络。

## 保留问题

部分电信短信实际送达后仍显示发送中，后续可能排队。SQW100-1 还保留重复收信反馈；Q10 电信浏览器修复尚未在该型号复测；SQC100-4 移动/联通历史入网未通过。所有这些状态仍允许试用，细节见 [适配表](COMPATIBILITY.md)。Root、匹配原生文件、当前 SIM 身份和完整恢复备份属于运行条件，不因开放型号而跳过。

## 版本与验证

历史实机结果按原版本保留。本版离线测试、包内自检、签名、下载哈希结果见 materials/open-model-release-validation-2026-11-08.json（发布完成时生成）；不把离线测试当成新版本整包硬件验收。Windows 未使用 Authenticode；BAR 为 development-mode 原生包。保留全部已知旧载荷升级指纹和恢复备份机制。
