下载 BAR 手动安装

适合已经 Root，并且已有可用 BAR 安装器的用户。

使用已有的 BAR 安装器

面向 OS 10.3.3.3216、已 Root 的 Q10、Q20、Passport 与 P’9983 全部目录后缀；实测结果按型号和版本单独记录。Root 本身不等于已有安装入口；先确认 BARinstaller 兼容当前 Root 方案并能正常使用。

下载 BAR · 0.1.0.45SHA-256

  1. 等系统出现 Root 成功提示。
  2. 从上方直链下载 BAR，核对同版完整 SHA-256；升级前先关闭原应用。
  3. 用已有的兼容 BAR 安装器打开文件，正常确认系统提示。安装后核对实际版本为 0.1.0.45。
  4. 打开应用，继续按手机版指南备份、开启与验收。

这里与桌面内置的是同一个 BAR。纯手机点击首装尚未单独完成验收；本机入口不可用时，使用桌面安装器辅助一次。

高级方式：AutoRoot v4 终端

需要可用的本机 Root 终端和受核验的 v4 安装器。下载同版引导 ZIP，核对摘要后按包内 INSTALL.txt 操作。v2、v3 不可直接套用。

下载引导 ZIP · SHA-256

同一任务的 SUD success 与实际注册版本都正确，才算安装通过。120 秒超时后的 completed 文本不能代替回执。结果未知时保留原任务和文件，不重复提交。
