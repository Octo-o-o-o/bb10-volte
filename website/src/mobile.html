BLACKBERRY 10 / NATIVE MOBILE

Root 之后，
把 VoLTE 装进手机。

已 Root 的 BB10，推荐使用原生 BAR 应用：由手机系统安装服务注册，随后在手机里管理 VoLTE。本机 BAR 安装器与电脑辅助首装，是进入同一个原生应用的两种入口。

候选版仍在验收，尚未公开发布。

Q20／联通、Passport／移动已完成完整恢复、卸载、重装、通话和短信；Q20 换移动卡、Passport 换联通卡也已完成本轮验收。Q10 的原生安装仍在验证。当前公开桌面版本仍为 v0.5.0-r15。

查看正式 Release 页面继续下载桌面 r15

只有正式 Release 列出手机版文件、校验信息和适用范围后，才按对应版本操作。本页不提供尚不存在的手机包下载地址。

推荐安装方式先选安装入口备份到通话验收备份保存在哪里更新与恢复已验证到哪里

RECOMMENDED / ROOT → BAR → SYSTEM INSTALLER

Root 后，优先走原生安装路线

用原生 BAR，让 BB10 正常注册应用。 应用沿用固定的应用与作者身份，便于覆盖升级。安装图标与启用无线服务分开；打开应用后，再备份和开启 VoLTE。

  1. 正常开机、解锁，等到系统的 Root 成功提示。
  2. 从同一可信发行版取得 BAR 与 SHA-256。已有兼容 BAR 安装器就用它打开；没有时，使用对应新版桌面的“更多 → 安装手机应用”辅助首装。
  3. 等系统安装完成，核对实际应用版本，再打开 BB10 VoLTE，按提示备份、开启、正常重启并验收通话。

公开桌面 r15 还没有“安装手机应用”新菜单。候选版需按同次交付说明操作；不会因为下载了 ZIP 就自动获得该入口。

AutoRoot v4 作者明确说明了 Root 成功提示后的未签名 BAR 安装、本机 Root helper 与包格式。本项目沿用这条原生路线。“推荐”是本项目针对已核对环境的选择，不代表 BlackBerry 官方认证，也不代表所有 Root 方案都可直接套用。查看 AutoRoot 作者说明。

日常脱离电脑与首次完全不用电脑，需要分别判断。Q20、Passport 的安装证据包含经可信 Root SSH 调用手机系统安装器；不能据此把“纯手机点击首装”写成已完成实测。

01 / FIRST INSTALL

先看手机上已有哪种入口

Root 是系统管理员权限。Root 标记、SSH 可连接、终端图标和能够安装 BAR，是不同条件；不能互相替代。首次出现系统安装或存储权限提示时，需要你在手机上正常确认。

A / 已有安装器

已经装好 BARinstaller

先确认它在当前 Root 方案下确实能安装原生 BAR，且手机有可用的本机 Root 执行入口。满足这两个条件，才可能全程在手机上安装与管理。

  1. 等手机版正式发布后，从项目 Release 获取该版本的 BAR 和校验信息。
  2. 按发行说明核对来源与完整 SHA-256，再用已有 BARinstaller 打开 BAR，正常确认系统提示。
  3. 核对实际安装版本，再打开 BB10 VoLTE 检查本机 Root 和设备条件。

如果 BARinstaller 还没装好，它自己也需要首次安装入口；下载一个 BAR 文件不会自动补齐这个前提。

B / 只有本机终端

有可用的 Root 终端

需要能在手机上实际执行 Root 命令的终端，以及发行版支持的 Python 和系统安装接口。普通终端或只有电脑能连的 SSH 不等于已具备这条路线。

  1. 等正式 Release 提供适用于当前 Root 方案的手机引导包。
  2. 把同一版本的引导包与 BAR 存到手机，核对来源和校验信息。
  3. 严格使用该发行版给出的本机命令，查看同一安装任务的结果与实际应用版本。

候选引导仍在实测。不要拼接其他版本的脚本，也不要把网页内容直接作为 Root 命令执行。

C / 电脑辅助一次

已 Root，但没有本机安装器

使用对应新版桌面的“更多 → 安装手机应用”：连接并解锁一台手机，检查身份，选择同次发行的 BAR，再确认安装。向导会核对完整包、系统回执和实际安装文件。

公开 r15 暂无此菜单；新向导仍随 Q10 首装进行验收。安装结果未知时，只检查原任务，不重复提交。

查看可信连接与恢复说明

D / 尚未 Root

先完成单独的 Root 准备

手机版不是 Root 工具，不能把未 Root 的手机直接变成可安装、可修改系统的设备。

先备份个人数据，按准确硬件型号选择桌面首次 Root 路线。涉及刷写时会清空数据，需要单独明确确认；不能跨机型使用固件。

查看首次 Root 的条件与已测范围

安装成功，要看实际版本

候选实测中，AutoRoot installer 在 120 秒超时后仍可能打印 completed。如果没有对应任务的 SUD success，而且应用注册版本没有变化，就不能记为安装成功。

保留原任务，检查系统安装结果和应用的实际版本是否与目标一致。仅有结束字样、图标或旧版能打开，都不足以证明新版本已安装；结果未知时不要反复提交安装。

02 / BACK UP, ENABLE, CHECK

装好以后，按这四步走

以下为候选版交互流程。使用自己的 SIM、号码和系统拨号器，仍按运营商套餐计费；SIM 需要开通 VoLTE 并有正常 LTE 数据。

  1. 检查手机，选好备份位置

    打开应用，确认型号、系统、当前 SIM 与检查结果。选择 SD 卡或内部存储；程序先保存原件并读回校验，再允许写入。

  2. 点“激活 VoLTE”，等待当前任务

    阅读并确认操作。任务提交后在手机后台继续；关闭界面不会取消已提交的任务。重新打开只查询原任务，不要重复安装。

  3. 按提示正常重启

    用电源菜单重启并解锁，先等系统 Root 成功提示，再打开应用一次。未打开时不要连续点图标；系统拒绝启动时，应用内等待页也无法运行。进入后会自动检查。Passport 网络策略变化时可能还需一次正常重启。

  4. 自己验证呼出、呼入、声音和 LTE

    用系统拨号器呼出一次，再从另一部手机呼入，分别接通至少 2 分钟，再做一次呼出。确认双方有声音、通话全程保持 LTE / 4G，再记录验证。应用不会替你拨号；IMS 已注册也不等于通话已通过。

通话记录只对应当前 SIM、本次开机和当前载荷版本。换卡应先正常关机；换卡、重启或版本变化后重新验收。短信、号码显示和长期待机也应分别实测。

03 / KEEP THE ORIGINALS

备份放在哪里，有什么区别？

SD 卡：优先选择可用的独立副本
卡已挂载并能通过写入和读回校验时，可以把原始备份保存到卡上。安装完成前保留 SD 卡；完成后建议再把副本保存在另一处。
内部存储：可以使用，但仍在同一台手机上
没有 SD 卡时可选内部存储。它便于本机恢复，却不能防止手机丢失、存储损坏或系统无法启动后取不出文件。之后可以再导出到 SD 卡。
以应用显示的导出位置为准
内部导出位于 /accounts/1000/shared/documents/BB10-VoLTE/ 下，SD 卡导出位于 /accounts/1000/removable/sdcard/BB10-VoLTE/ 下；每次任务有自己的子目录。保留原始备份和回执，脱敏诊断报告不能代替原始备份。

04 / UPDATES & RESTORATION

更新、停用与恢复

适配载荷更新与应用 BAR 升级是两件事

候选应用中的“检查更新”和离线 ZIP 入口用于运行组件与适配载荷。程序会核验发布者签名；在线检查失败时可以使用同一发行版的可信离线包。已内置的安装载荷和离线包不需要联网下载，注册和通话仍需要运营商网络。

界面应用自身升级使用新的 BAR，沿用同一应用身份。按 Release 的版本要求，通过已有安装入口替换，再核对实际应用版本。不能把 ZIP 更新完成当作 BAR 已升级。

恢复完成后，再移除应用

在管理页选择停用并恢复、回滚或完整卸载，按提示正常重启并继续原任务。卸载可能需要分阶段重启；文件已移除不等于恢复已核对完成。仅删除桌面图标不会恢复服务配置，也不会移除 Root。

任务中断、未知文件或备份冲突时，保留原任务和原件，先重新检查或导出报告。恢复只使用有所有权与校验证据的内容，不用反复安装来覆盖未知状态。

手机版与新版桌面使用管理协议 2。r14 / r15 / r16 旧桌面不能完整管理新载荷，需与手机服务协议匹配的新版管理端。旧客户端被拒绝时，应升级管理端并按发行说明完成停用、恢复与正常重启后接管。

05 / EVIDENCE & DEVICE SCOPE

手机端验收到哪一步，按机型看

Q20 · SQC100-2

应用 v12 / 服务 r18：联通卡已完成恢复、卸载、重装、通话、短信和验收保存。换移动卡后，通话、短信及验收记录保留通过。

Passport · SQW100-4

应用 v12 / 服务 r18：移动卡完整流程通过。换联通卡后，经正常重启完成网络策略切换，机主确认通话、短信和验收保存均正常。

Q10 · SQN100-3

原生应用首装仍在验证，包括 QNX 进程启动、包解压和系统安装回执。旧版语音通过，不能代替本次手机应用安装成功。

核对日期：2026 年 11 月 2 日，Asia/Shanghai。最新界面包、纯手机点击首装仍需各自验收。Passport 此前一次孤立唤醒重启已由机主接受，但其根因不声称已修复；长期稳定性仍需单独观察。

现有历史范围为 OS 10.3.3.3216 的 Q10 SQN100-3、Q20 / Classic SQC100-2、Passport SQW100-4。r7 / r8 的三机三网九项语音组合记录继续保留。r14 短信验证覆盖 Q20＋联通、Passport＋移动；其他短信组合不能据此扩写。

每个新的手机候选包仍需分别核对首次安装、应用到 Root、界面升级、大小屏操作和恢复；上面的通过结论属于所记录的 v12/r18 组合。识别到机型、编译成功或看到图标都不能代替这些结果。

其他 Q10 / Classic 可以查看单独的实验路线，但仍要通过原生文件散列、ABI、SIM、网络和恢复检查；手动启动且不自动启用。SQC100-4 和其他未验收变体不标为已支持。未知设备可导出部分兼容性报告，没有“忽略检查继续”入口。
