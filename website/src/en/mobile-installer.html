BB10 VOLTE / GUIDES

Install with the desktop app

Recommended for first use. The matching BAR is already bundled.

Before you start

Desktop v0.5.0-r20 · mobile 0.1.0.15. Requires a rooted Q20 SQC100-2 or Passport SQW100-4, OS 10.3.3.3216, a trusted native Root connection and the verified AutoRoot v4 installer. Q10 native installation remains under separate testing.

Windows x64macOS · Universal

SHA-256

  1. Connect one phone over USB, unlock it and wait for the system Root success notification.
  2. Open “More → Install phone app”. The bundled BAR is verified automatically; no separate download is needed.
  3. Choose “Check phone”, verify the model and confirm “Install to phone”. Close the existing phone app before upgrading.
  4. Keep the connection until the system receipt and installed files pass verification. If interrupted, reconnect the same phone and check the original task; do not resubmit.
  5. Open the phone app, accept normal permissions and follow the backup, activation and call checklist.

This registers the app; wireless service activation is a separate phone action. After first installation, normal management runs on your phone.
