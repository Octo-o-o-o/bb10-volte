使用安装器安装

推荐首次使用。匹配的 BAR 已内置，下载一个桌面包就够了。

准备好再开始

桌面 v0.5.0-r42 · 手机 0.1.0.43。四大家族目录后缀均已开放。需要有效 Root、OS 10.3.3.3216、可信的原生 Root 连接及可用的系统安装器。各型号实测范围单独记录，不把历史结果当成本版整包验收。

Windows x64macOS · Universal

SHA-256

  1. 打开桌面应用，USB 连接一台手机，解锁，等系统出现 Root 成功提示。
  2. 打开「更多 → 安装手机应用」。程序自动核对内置 BAR，不必另外下载或选包。
  3. 点击「检查手机」，确认型号后点击「安装到手机」。覆盖升级前先关闭手机上的 BB10 VoLTE。
  4. 保持连接，等待系统回执和实际安装文件校验通过。若中断，恢复同一台手机的连接并检查原任务，不要重复提交。
  5. 打开手机应用，正常确认权限，继续按备份、开启与通话验收步骤操作。

这一步安装应用图标；VoLTE 服务由手机应用另行开启。首装成功后，日常管理可以脱离电脑。
